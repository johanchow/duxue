## 一、背景与定位

### 1.1 系统定位

在读学系统中，记忆系统（**孩子理解引擎 / Child Understanding Engine**）是支撑个性化答疑、排期校准与客观评估的**纯后端长期智能底座**。

它不面向学生提供独立的业务操作界面，而是基于**客观事实事件账本（Fact Event Ledger）**，跨时段感知、抽取、整合与衰减对学生（Ward）学习行为与学科认知的客观理解，并按需向各个业务域（`Tutoring`、`Planning`、`Evaluation`）注入上下文记忆（`MemoryBundle`）。

```text
┌────────────────────────────────────────────────────────────────────────┐
│                    客观事实事件输入源 (Objective Fact Producers)        │
│  ① 桌面视觉观察 (duxue-cam) │ ② 启发答疑教学事实 (Tutoring) │ ③ 会话执行 (Study) │
└──────────────┬─────────────────────────────┬───────────────────────┬───┘
               │ 产生客观行为信号            │ 产生客观教学 Fact     │ 产生实际用时事实
               ▼                             ▼                       ▼
┌────────────────────────────────────────────────────────────────────────┐
│             孩子理解引擎与记忆系统 (prd-memory.md / 纯系统能力)          │
│                                                                        │
│  ┌──────────────────────────────────────────────────────────────────┐  │
│  │ 1. 短期工作记忆 (Working Memory · 会话/线程级)                   │  │
│  │    - 当前 Thread 最近 8 句窗口 · 活跃题目状态与已授权图片        │  │
│  └──────────────────────────────────────────────────────────────────┘  │
│  ┌──────────────────────────────────────────────────────────────────┐  │
│  │ 2. 近期事件记忆 (Episodic Memory · 有独立客观事实来源的经历)     │  │
│  │    - 近期答疑攻克/卡壳经历 · 任务执行耗时流水 · 好奇心信号池     │  │
│  └──────────────────────────────────────────────────────────────────┘  │
│  ┌──────────────────────────────────────────────────────────────────┐  │
│  │ 3. 长期客观画像 (Semantic Claims & Signals · 带时间衰减)         │  │
│  │    - 学科知识点掌握度与卡点特征 · 专注耐力基线 · 持续兴趣主题    │  │
│  └──────────────────────────────────────────────────────────────────┘  │
│                                                                        │
│  🚫 严格隔离边界：Ward 课后自由总结（主观自述）归属 Evaluation 域，      │
│     绝不作为客观事实写入 Memory，也不生成长期人格/情绪诊断画像！         │
└────────────────────────────────────┬───────────────────────────────────┘
                                     │ 按需组装 MemoryBundle 注入
                                     ▼
┌────────────────────────────────────────────────────────────────────────┐
│                        业务模块消费 (Domain Consumers)                  │
│  → 注入 Tutoring：提供近期相关答疑经历与知识点历史表现，调整启发步长    │
│  → 注入 Planning：提供同类任务历史实际耗时基线，生成时长软建议          │
│  → 注入 Evaluation：提供近期客观行为与卡点基线，支撑《伴学闭环实况单》  │
└────────────────────────────────────────────────────────────────────────┘
```

### 1.2 核心设计原则与隔离红线（不可违反）

1. **只收客观事实，严禁混入主观自述（Self-Review Isolation）**：
   - 记忆引擎只消费有独立客观事实来源的事件（如 `Tutoring` 结算的教学事实、`StudySession` 实际执行记录、`duxue-cam` 客观视觉状态）；
   - **Ward 的课后自由总结（原话与六维条目）属于主观自述，严格留在 `Evaluation` 域**：停止投递 `self_review.submitted`，不生成 `daily_review` Episode，不在 `MemoryBundle` 中复制六维条目；孩子自述的“我懂了”“这方法有效”绝不能单独当成客观能力或策略效果写入 Memory。
2. **去人格化与去临床诊断化**：
   - 严禁将短期情绪表达（`affect`）或环境上下文（`context`）固化为长期人格画像或家庭关系/心理焦虑画像；
   - 严禁出现“懒惰、磨蹭、笨拙、多动症”等道德评判或临床标签。
3. **动态成长自适应（时间半衰期衰减）**：
   - 孩子处于快速成长期，历史上的“某知识点卡壳”或“某时段易停滞”具备时间半衰期（Half-life）。随着近期客观表现改善，旧 Claim 权重自动衰减，避免给孩子贴永久标签。
4. **纯系统底座，无学生端独立 UI**：
   - 学生端不展示“记忆列表”或“能力参数看板”；仅在 Guardian 端【设置 / 隐私与数据管理】中提供合规透明度查看与一键清除/重置能力。

## 二、三层记忆架构与数据边界

技术表映射与详细契约以 [`docs/technical/domain-memory.md`](../technical/domain-memory.md) 为单一事实源。

### 2.1 第一层：短期工作记忆（Working Memory）
- **生命周期**：当前对话 Thread / 单次答疑或排期 Run 期间。
- **核心内容**：
  - `Companion` 当前 Thread 最近 8 句对话窗口（上限 2400 字、不含系统自动追加的尾巴）与最多 8 张已授权图片；
  - `Tutoring` 当前活跃题目的推理状态、已提交证据与答案保护许可（`permit()`）；
  - `Planning` 当前待澄清槽位与未确认日程草稿。

### 2.2 第二层：近期事件记忆（Episodic Memory）
- **生命周期**：滚动保留近期有独立客观事实来源的学习经历（`episodic_memories`）。
- **核心内容**：
  1. **答疑教学事件**：近期提问过的具体学科题目摘要、卡点阶段、经过几轮引导是否独立解出、或标记为“待问老师”；
  2. **任务与会话执行流水**：实际执行的任务耗时与预估偏差、客观桌面专注与停滞分布；
  3. **好奇心信号池（`Interest Signal`）**：伴学过程中提出的非作业类好奇心问题记录。
- **明确排除**：不存储 `daily_review`（今日总结自述），不存储已退役的 `focus_kits`（专注锦囊）。

### 2.3 第三层：长期客观画像（Signals & Semantic Claims）
- **生命周期**：跨周期聚合提炼，带置信度与时间衰减函数。
- **核心维度**：

| 画像维度 | 客观事实来源 | 业务消费方与用途 |
| :--- | :--- | :--- |
| **学科认知与卡点特征** | `Tutoring` 教学结算事实（独立解出 / 多轮卡壳 / 待问老师） | 注入 `Tutoring`：针对薄弱前置概念主动放小启发步长或优先提供结构化配图（`visual`） |
| **任务耗时与专注基线** | `StudySession` 实际用时 + `duxue-cam` 净专注动笔时长 | 注入 `Planning`：当孩子排期预估偏差较大时，提供有依据的时长软建议 |
| **持续兴趣主题** | 跨多次会话重复出现的 `Interest Signal` | 供伴学举例类比时选用孩子感兴趣的主题素材 |

## 三、合规、安全与隐私管理

1. **家庭数据严格隔离**：所有记忆检索与写入强制绑定 `ward_id` 与家庭授权关系，严禁跨家庭串扰。
2. **Guardian 透明可控与被遗忘权**：
   - Guardian 可在隐私设置中查看系统记录的客观学科与习惯摘要；
   - Guardian 发起“重置学习记忆”或“注销账号”时，服务端按 [`domain-memory.md`](../technical/domain-memory.md) 数据删除边界物理擦除对应账本、Episode 与 Claim。

## 四、验收标准

| ID | 验收场景 | 期望结果 | 优先级 |
| :--- | :--- | :--- | :--- |
| **AC-M01** | **答疑客观事实沉淀** | Ward 完成一次启发答疑会话结算后，对应的知识点卡点与独立解出状态正确写入事实账本与 `episodic_memories` | P0 |
| **AC-M02** | **主观自述严格隔离** | Ward 确认今日原话总结后，不触发 `Memory` 写入，`MemoryBundle` 中不包含自述六维条目 | P0 |
| **AC-M03** | **历史弱项动态衰减** | 某知识点连续多日未再出现卡壳且新近独立解出后，旧薄弱 Claim 权重按衰减规则下降 | P0 |
| **AC-M04** | **数据删除边界执行** | 发起 Ward 记忆重置或删除请求后，关联的客观记忆数据完整清除，不留脏索引 | P0 |
