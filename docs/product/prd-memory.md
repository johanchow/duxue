## 一、背景与定位

### 1.1 系统定位

在读学系统中，记忆系统（**孩子理解引擎 / Child Understanding Engine**）是支撑个性化伴学、客观评估与成人受权教研的**纯后端长期智能底座**。

它不面向学生提供独立的业务操作界面，而是基于**客观事实事件账本（Fact Event Ledger）**，跨时段感知、抽取、整合与衰减对学生（Ward）学习行为、学科认知与兴趣主题的客观理解，并按需通过受权只读接口（`MemoryBundle`）服务以下消费方：
- **`Tutoring`（Ward 作业答疑）**：提供近期相关答疑经历与薄弱前置概念，调整启发步长；
- **`Evaluation`（晚间客观交付）**：提供近期客观行为、卡点与兴趣基线，支撑《伴学闭环实况单》；
- **`EduAgent`（Guardian / Coach 成人工作台 · 显式受权只读）**：当家长或伴学师显式选择某位已绑定 Ward 时，只读读取其近期卡点与薄弱点摘要，用于针对性备课、变式出题或家校沟通。

> 📌 **演进变更（v3.0）**：随着 `Planning` 与 `Reflection` 正式退场，记忆引擎不再服务排期耗时建议，也不存在 `SelfReview` 自述流；同时新增消费来自 Ward 自由探索与创作的 **`Interest Signal`（兴趣与创作信号）**，并与客观学科掌握度严格隔离。

### 1.2 核心设计原则与隔离红线（不可违反）

1. **只收客观事实，严格隔离学业掌握与兴趣创作**：
   - 学科掌握度与卡点特征**只能**来自有独立客观事实来源的教学与行为事件（`Tutoring` 结算事实、读学Eye 客观视觉状态）；
   - Ward 自由画图、编故事与好奇心探索沉淀为 **`Interest Signal`**，**绝不混入客观学科掌握度评估**。
2. **成人端受权只读、严禁隐式写回**：
   - Guardian / Coach 在教育通用 Agent 工作台关联某位 Ward 进行批改、备课、出题或试探提问时，仅可**只读**读取该生的 `MemoryBundle`；成人的任何操作**绝不自动写入**该生的 `Memory` 或 `TutoringSession`。
3. **去人格化与去临床诊断化**：
   - 严禁将短期情绪或偶发行为固化为长期人格标签、心理/临床诊断或道德评判（如“懒惰、磨蹭、多动”）。
4. **动态成长自适应（时间半衰期衰减）**：
   - 历史上的“某知识点卡壳”或“某时段易停滞”具备时间半衰期；随着近期客观表现改善，旧 Claim 权重自动衰减，避免给孩子贴永久标签。
5. **纯系统底座，无学生端独立 UI**：
   - 学生端不展示“记忆列表”或“能力参数看板”；仅在 Guardian 端【设置 / 隐私与数据管理】中提供合规透明度查看与一键清除/重置能力。

## 二、三层记忆架构与数据边界

技术表映射与详细契约以 [`docs/technical/domain-memory.md`](../technical/domain-memory.md) 为单一事实源。

### 2.1 第一层：短期工作记忆（Working Memory）
- **生命周期**：当前对话 Thread / 单次 Agent Run 或作业答疑期间。
- **核心内容**：
  - 当前 Thread 最近对话窗口与已授权图片；
  - `Tutoring` 当前活跃作业题的推理状态、已提交证据与答案保护许可（`permit()`）；
  - 当前 `AgentRun` 的临时规划状态与产物版本指针。

### 2.2 第二层：近期事件记忆（Episodic Memory）
- **生命周期**：滚动保留近期有独立客观事实来源的经历（`episodic_memories`）。
- **核心内容**：
  1. **作业答疑教学事件**：近期提问过的具体学科题目摘要、卡点阶段、经几轮引导是否独立解出、或标记为“待问老师”；
  2. **客观桌面行为流水**：来自读学Eye 的有效专注读写与停滞卡壳分布；
  3. **好奇心与创作信号池（`Interest Signal`）**：伴学或自由探索过程中提出的非作业好奇心问题与创作主题。

### 2.3 第三层：长期客观画像（Signals & Semantic Claims）
- **生命周期**：跨周期聚合提炼，带置信度与时间衰减函数。
- **核心维度**：

| 画像维度 | 客观事实来源 | 业务消费方与用途 |
| :--- | :--- | :--- |
| **学科认知与卡点特征** | `Tutoring` 教学结算事实（独立解出 / 多轮卡壳 / 待问老师） | 注入 `Tutoring` 调整启发步长；供成人工作台受权只读以针对性备课与变式出题 |
| **桌面专注基线** | 读学Eye 净专注动笔时长与停滞分布 | 注入 `Evaluation` 支撑晚间《伴学闭环实况单》 |
| **持续兴趣主题** | 跨多次会话重复出现的 `Interest Signal`（含自由创作足迹） | 供伴学举例类比、自由探索引导与晚间报告正向洞察使用（不计入学业掌握度） |

## 三、合规、安全与隐私管理

1. **家庭数据严格隔离**：所有记忆检索与写入强制绑定 `ward_id` 与 Guardian-Ward 授权关系，严禁跨家庭串扰。
2. **Guardian 透明可控与被遗忘权**：
   - Guardian 可在隐私设置中查看系统记录的客观学科与兴趣摘要；
   - Guardian 发起“重置学习记忆”或“注销账号”时，服务端按 [`domain-memory.md`](../technical/domain-memory.md) 数据删除边界物理擦除对应账本、Episode 与 Claim。

## 四、验收标准

| ID | 验收场景 | 期望结果 | 优先级 |
| :--- | :--- | :--- | :--- |
| **AC-M01** | **答疑客观事实沉淀** | Ward 完成一次作业启发答疑结算后，对应知识点卡点与独立解出状态正确写入事实账本与 `episodic_memories` | P0 |
| **AC-M02** | **自由创作信号隔离** | Ward 在自由探索态完成画图或故事共创后，仅沉淀 `Interest Signal`，不新增或修改客观学科掌握度 Claim | P0 |
| **AC-M03** | **成人工作台只读隔离** | Guardian 显式关联某位 Ward 使用通用 Agent 批改/备课出题时，可准确读取其近期卡点，但该 Ward 的 `Memory` 写入次数为 0 | P0 |
| **AC-M04** | **历史弱项动态衰减** | 某知识点连续多日未再出现卡壳且新近独立解出后，旧薄弱 Claim 权重按衰减规则下降 | P0 |
| **AC-M05** | **数据删除边界执行** | 发起 Ward 记忆重置或删除请求后，关联的客观记忆数据完整清除，不留脏索引 | P0 |
