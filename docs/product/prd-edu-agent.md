## 一、产品背景与核心定位

### 1.1 从“孤立场景拼盘”到“统一教育通用 Agent”

此前读学在交互侧分为两套割裂路径：
- **Ward（学生端）**：被限定在 `planning`（计划）/ `tutoring`（答疑）/ `reflection`（复盘）三个固定路由里；
- **Guardian / Coach（成人端）**：仅提供无状态单题体验问答与单题动态课件（`MentorCourseware`）。

本设计确立两项根本性产品升级：
1. **彻底退场 `planning`（线上计划与任务池）与 `reflection`（结构化每日自述）**：回归“零前置负担、弱约束高可靠”的初心，仅保留 L0 静默桌面观察与可选的轻量专注挑战（Sprint）。
2. **双端共用一套「教育通用 Agent + 多形态可修订产物工作区（EduArtifact）」**：
   - 底层是具备**自主规划、学科核验工具、多模态创作技能、可版本化产物工作区**的通用教育 Agent；
   - **Guardian / Coach 端**与 **Ward 端**不再是两套割裂系统，而是同一套 Agent 内核在不同**角色权限与安全策略（Role Policy）**下的投射。

### 1.2 核心价值主张（为什么不是通用聊天套壳）

| 痛点 | 通用聊天大模型（如纯对话 Bot） | 读学教育通用 Agent |
| :--- | :--- | :--- |
| **学科可靠性** | 心算易错、批改常漏错或错怪、出题可能无解 | **验证优先（Verification-First）**：计算/推理/批改/出题自验全部强制接入确定性算子与多路核验，存疑显式标注 |
| **交付形态** | 一长串线性聊天记录，做完即焚、难以局部修改 | **对话流与产物区分离（EduArtifact）**：交付动态课件、批改诊断单、教案/变式卷、绘本/画作/卡片，支持局部修订、Undo/Redo 与资产库沉淀 |
| **教育场景适配** | 缺乏学生防泄题、防代写与防分心机制 | **角色策略与专注护栏**：成人端全生产力开放；学生端守住答案保护、作业防代写与专注态软边界 |
| **个性化上下文** | 不了解具体孩子，只能泛泛而谈 | **受权学情只读联动**：成人显式指定绑定孩子时，可只读其近期卡点与实况报告，生成千人千面的讲义、练习与家校反馈 |

## 二、目标用户与双端策略矩阵

同一套 Agent 内核，按登录角色应用两套严格隔离的 **Role Policy**：

| 能力维度 | Guardian / Coach（成人策略：教育生产力工作台） | Ward（学生策略：启发伴学 + 自由创作探索） |
| :--- | :--- | :--- |
| **共享通用底座** | 自主规划、多轮局部修订（Patch）、Undo/Redo、动态数理演示（`MathStage`）、画图/思维导图、故事/文档/卡片生成、个人资产库 | **全部共享**（自动适配学段认知水平与适龄交互） |
| **解题与答疑** | 直接给核验结论、完整推导、多解法对比、深度动态课件 | **严守答案保护红线**：分步启发、独立泄露裁判、对话内微验证产出《独立解题凭证》 |
| **作业/试卷批改** | 支持整页/多页拍照批改、逐题定位手写、错因归类、生成巩固题 | **关闭**（不提供整页批改或代判选项对错，杜绝刷答案） |
| **备课与出题** | 教案/讲义生成、按考点或错题生成变式练习卷（出题后先自解自验） | **关闭整卷出题**（可按需请求 1 道巩固练习题，走启发模式） |
| **自由创作（画图/故事/演示/卡片）** | 直接产出可交付图文/课件/家校简报 | **开放共创与探索，但严守作业代写防线**：识别为课内作文/手抄报/作业要求时切为启发共创（给框架、接龙、提修改建议，不代写成品）；纯兴趣创作放开协同 |
| **专注与防沉迷边界** | 无限制 | **「专注态 vs 自由探索态」软守护**：Sprint 或未完成作业题期间不主动诱导娱乐创作，遇偏题先温和提醒 |
| **学情数据边界** | 显式指定某位绑定孩子时**受权只读**其卡点与报告；**严禁隐式写回**孩子客观 `Memory` | 作业问答写入客观教学事实与凭证；自由创作仅沉淀为**好奇心/创作足迹**，不混入“学业掌握度” |

## 三、Teacher / Coach / Guardian 成人端需求目标（MVP 闭环）

定位：**面向学科老师、教培老师与伴学师的教研与教学生产力工作台（G4），同时兼任家长日常辅导副驾驶（G3）**——无需先绑定学生即可独立使用。

### 3.1 统一任务入口与复合指令
- 原「问答」Tab 升级为**教育 Agent 工作台**（保留 `体验孩子怎么学` 独立体验开关，便于家长试体验学生视角）。
- 支持文字、语音、单张/多张拍照输入，支持**一句话下达复合目标**。例如：
  - *“帮我批改这两页初二几何作业，把错题做成 5 分钟讲清的动态课件，再出 2 道同类巩固题。”*
  - *“结合小明这周的错题情况，帮我备一节 15 分钟的分数应用题复习讲义，再写一段发给家长的沟通反馈。”*
- 复杂任务展示透明的执行阶段（规划中 → 读图/核验中 → 生成产物中），支持中途补充要求或取消。

### 3.2 首批核心 Skills（三大拳头闭环）

1. **作业/试卷批改与错因诊断（`grading_report`）**
   - **突破旧限制**：解除原 `prd-user.md §7.2` 对成人端“禁止整页试卷处理”的限制，支持单题、整页或多页纸质作业/试卷拍照批改。
   - **逐题核验与诚实标注**：逐题识别题面与手写过程，调用确定性求解核验内核比对正误；**手写模糊、涂改严重或开放题核验低置信时，显式标为「待人工复核」**，宁可存疑不冤枉、不漏判。
   - **结构化错因诊断**：对错题归类错因（计算失误 / 概念混淆 / 条件漏读 / 推理跳步），支持一键基于错题触发「生成讲题课件」或「出同类巩固题」。

2. **深度讲题与动态交互课件（`interactive_courseware`）**
   - **完全承接现有基线**：复用 `MentorCourseware` 的按题灵活编排、`MathStage` 离线 Web 数理舞台（预置组件 + 后续隔离生成 JS）、静态降级、对话式局部修订与 Undo/Redo。
   - 在通用 Agent 下，动态课件既可由单题直接触发，也可作为批改或备课任务的子产物自动生成。

3. **备课教案、讲义与变式出题（`lesson_pack`）**
   - 支持按学科、年级、知识点、错题或上传教材页，生成结构化教案、微专题讲义、分层变式练习卷（含答案与解析分离视图）及家校沟通简报。
   - **出题自验闭环（硬要求）**：Agent 生成的每一道客观题/计算题/几何题，在交付前必须自动调用求解核验工具完成**自解自验**，确保条件完备、无歧义且标准答案无误；未通过自验的题目禁止标为 `verified`。

### 3.3 受权学情上下文（显式绑定，只读不写）
- 成人工作台顶部提供可选的**「关联学生上下文」选择器**（默认不关联，保持无状态通用模式；点击可显式选择已绑定的某位 Ward）。
- 关联后，Agent 可**只读**读取该生近期 `Evaluation` 实况报告、解题凭证与 `Memory` 客观卡点摘要，用于针对性备课、变式出题或撰写家校沟通反馈。
- **隔离铁律**：关联学情后，成人在 Agent 中的一切批改、试探、备课与修订操作**不会自动写入该生的 `Memory` 或 `TutoringSession`**。

### 3.4 个人教学资产库（升级原「我的课件」）
- 原「我的课件」升级为**「我的资源库」**，统一承载成人主动保存的多形态产物（动态课件 / 批改诊断单 / 教案与变式卷）。
- 支持按类型筛选、重命名、删除、跨端/冷启动后同 ID 重开继续用 Agent 对话修订与 Undo/Redo，以及预留导出/打印分享能力（后续 Web 工作台同源承接）。

## 四、Ward 端需求目标（MVP 闭环）

定位：**写作业时克制高效的启发伙伴 + 作业外激发好奇心的创作与探索伙伴**。

### 4.1 安静首页底色与极简入口
- 彻底移除「作业计划 / 待办清单 / 今日复盘总结」入口与对话路由。
- **保留默认安静首页 + 底部唯一 `VoiceComposer`（语音 + 拍照 + 文字）+ 可选「试一轮专注挑战（Sprint）」**。
- **克制原则**：不在 Ward 首页堆砌娱乐创作广场、热门模板推荐流或红点诱导，创作与探索均由孩子通过自然语言或主动意图自然触发。

### 4.2 作业启发答疑（红线与教学方法论）

作为教育通用 Agent 在 Ward 作业场景下的强护栏技能，严格遵循以下原则与方法论（技术契约见 [Tutoring Domain](../technical/domain-tutoring.md) 与 [答疑表达设计](../technical/domain-tutoring-presentation.md)）：

1. **教学优先，技术服务于教学**：设计回答、引导与配图时，先回答“一位好老师面对这个孩子、这道题会怎么讲”，技术只在安全不变量（答案保护、内容安全、端侧稳定）上有否决权，不因技术限制悄悄降级教学方案。
2. **苏格拉底小步启发与卡点诊断**：
   - 不设固定提示等级，按题目实际推理链与孩子当前回答诊断卡点，**每轮只推进一个孩子能独立完成的最小下一步**；
   - 纯记忆/原子事实直接回答，有逻辑推理层次的留给孩子，严禁首轮输出最终选项、数值答案或完整求解过程；
   - 长时间卡住时不泄答案，改为换表征、拆细小目标、给同构简单例题或建议记入“待问老师”。
3. **对话内微验证与《独立解题凭证》**：
   - 收尾引导孩子在对话内独立说出或算出最终关键结果，作为客观事实沉淀为《独立解题凭证》；
   - 未展示完整过程时不轻率断言“全对”，选择题/判断题不逐项代判对错。
4. **主动视觉支架与多模态发音（`pronounce`）**：
   - 数量关系、空间排列、过程变化或孩子反复困惑时主动提供示意图，明确要求画图时必须交付图（保留孩子尚未完成的计算与结论，受视觉防泄题门禁约束；画不出时如实说明，不以文字步骤敷衍代替）；
   - 英语/语文朗读与跟读场景支持发音示范（`pronounce`）；复杂原理理解可调用 `MathStage` 互动演示（仅展示原理结构，不直接画出待求结果）。
5. **青少年安全、情绪抚慰与清空历史边界**：
   - 违规内容毫秒级阻断；识别出强烈自我否定或极端情绪危机（如“我太笨了想放弃”）时暂停讲题，切换温和情绪抚慰并提醒家长；
   - 清空可见历史对话仅重置短期对话视图，不删除已保存作品、学习事实记录与长期记忆。

### 4.3 自由创作与主动探索（MVP 新增）
在答疑之外，首批开放三类高频适龄创作/探索技能，以轻量 `EduArtifact` 形式交付，支持孩子语音对话局部修改与 Undo/Redo：
1. **画图与互动理解**：画科学原理图、思维导图、插画，或打开可拖拽参数的数理/科学互动小实验（复用 `MathStage` 探索模式）。
2. **故事与绘本共创**：和 AI 一起构思角色、情节并逐页生成图文故事/小绘本，支持语音说“把小猫改成橘色”“把结局改得更搞笑”。
3. **知识卡片与趣味探索**：围绕偶发好奇心（如“为什么天是蓝色的”“恐龙怎么灭绝的”）生成图文并茂的知识闪卡或对比图册。

### 4.4 两大核心护栏：作业代写防线 + 专注态软边界
1. **作业代写防线（共创 vs 代写）**：
   - 独立语义 Judge 区分「课内作业/作文任务」与「纯兴趣自由创作」；
   - 识别为语文作文、读后感、英语书面表达、手抄报作业时，强制进入**启发共创模式**（帮列提纲、分段轮流接龙、给出润色建议，**禁止一键输出可直接照抄的成品**）；
   - 所有生成图文与故事强制经过未成年人内容安全审核（严禁暴力、惊悚、不良引导与过度拟人化情感依赖）。
2. **「专注态 vs 自由探索态」软边界**：
   - 当孩子处于 **Sprint（专注挑战）进行中**，或**当前存在未完成的受保护作业题**时，系统判定为**专注态**；
   - 专注态下若孩子发起明显偏离当前学习的娱乐创作（如“帮我编个游戏故事”），Agent 先给出一次温和守护提示（如*“你正在这一轮专注挑战里，要不要先做完手头这一小步，结束后来一起创作？”*）；
   - 若孩子明确坚持切换，允许进入自由探索态，但不打断计时归属统计，并在晚间报告中如实区分两类时长。

### 4.5 我的作品与探索册
- 收在 Ward 端右上角「⋯」更多菜单中（不占首页视觉权重），沉淀孩子主动保存的画作、故事绘本与知识卡片，支持随时重开继续语音修订。

## 五、晚间闭环交付升级（Evaluation & Memory 联动）

家长端（`Guardian / Coach`）晚间交付在移除 `SelfReview`（孩子自述）后，升级为三个清晰、可信的客观模块：

1. **《伴学闭环实况单》（严格分口径）**：
   - 明确分栏呈现：**「线下作业专注时长」**（来自 L0 读学Eye 与作业答疑）与**「AI 自由探索/创作时长」**（来自 Ward 自由探索态）；
   - **底线规则**：绝不把孩子玩 AI 画图/编故事的时间混算进“有效写作业时长”。
2. **《独立解题凭证》**：沿用既有防伪铁证机制（原题 + 卡点 + 孩子独立推导确认）。
3. **「好奇心与创作足迹」（新增轻量模块）**：
   - 汇总孩子当天主动探索的主题与保存的创意作品缩略预览（如*“作业后探索了太阳系轨道，并共创了一篇 3 页《火星小狗》故事”*）；
   - 将家长对“孩子是不是在玩 AI”的焦虑，转化为看见孩子兴趣与创造力的正向洞察。
4. **Memory 隔离**：自由探索与创作仅作为 `Interest Signal` 沉淀，绝不混淆写入客观学科掌握度画像。

## 六、终端形态与分期路线

- **首发载体**：优先在 `duxue-app`（兼容手机与平板横竖屏）演进，API 与 Artifact 协议保持终端无关，为后续独立 **Web 教师/伴学师工作台**（多页批量批改、大屏备课排版、PDF 导出打印）预留同源接入。

| 阶段 | 核心交付 | 验证目标 |
| :--- | :--- | :--- |
| **Phase 1：骨架抽象与退场清理** | 退场 `planning`/`reflection` 路由与入口；将 `MentorCourseware` 平滑抽象为 `EduArtifact` 统一容器；搭建受 Role Policy 约束的 `EduAgentOrchestrator` 骨架 | 原有导师动态课件与学生启发答疑 100% 回归无退化 |
| **Phase 2：Guardian 端生产力 MVP** | 上线「整页批改诊断（`grading_report`）」、「备课/变式出题自验（`lesson_pack`）」与「受权只读学生学情上下文」；「我的课件」升级为「我的资源库」 | 批改低置信诚实标待复核、出题自验通过率、复合任务端到端跑通 |
| **Phase 3：Ward 端创作探索与晚间足迹** | 开放 Ward 端「画图/互动理解 + 故事绘本/知识卡片共创」与「我的作品」；上线专注态软守护、作业代写防线；晚间报告分口径时长 + 创作足迹上线 | 作业防泄题/防代写不退化、专注态提醒不误伤、家长端时长分口径准确 |
| **Phase 4：Web 工作台与生态扩展** | 复用同源协议建设 Web 端教师/伴学师工作台，支持批量试卷处理、教案/练习卷 PDF 导出与自定义教学模板 | 赋能 B2C 晚托班 1 对 15 高频备课与批改场景 |

## 七、核心验收标准（产品级）

1. **复合任务闭环（Guardian）**：家长上传一页包含 2 道错题的数学作业并说“批改这页作业，把错题做成动态讲解，再出 2 道同类练习”，Agent 能自主拆解并交付批改诊断单、动态课件与经自验的变式题，且每份产物均支持对话局部修订与 Undo/Redo。
2. **批改与出题诚实红线**：面对模糊手写或无法确定等价性的答案，系统标为「待人工复核」而不硬判对错；生成的变式题若自解核验未通过，绝不标为 `verified`。
3. **受权只读学情隔离**：Guardian 关联某位 Ward 生成复习讲义与练习卷后，内容准确引用该生近期卡点，但该生的 `Memory` 与 `TutoringSession` 写入次数为 0。
4. **Ward 端创作与防代写双轨**：Ward 说“帮我写一篇 400 字环保作文交作业”触发启发共创（不给成品全文）；说“和我一起画一个恐龙宇航员的故事”则生成可语音局部修改的图文故事卡片并可存入「我的作品」。
5. **Ward 专注态守护与晚间分口径**：Ward 在 Sprint 期间发起偏题娱乐创作时收到温和专注提醒；若切换探索，当晚 Guardian 端《伴学闭环实况单》中「作业专注」与「自由探索/创作」时长严格分离，并展示当天创作足迹。
