## 一、背景与定位

### 1.1 产品定位

本模块（Evaluation & Reflection）承担读学系统在每日或单次学习会话收尾时的两项核心职责：
1. **面向家长与伴学师（Guardian / Coach · L0/L1 必达交付）**：即使家长未导入作业、孩子未建线上计划、也未手动做课后总结，系统依然基于桌面客观视觉状态机与答疑过程事实，按**证据版本化（Evidence Versioning）**稳定生成当晚的**《伴学闭环实况单》**与**《独立解题凭证》**，兑现“解放家长陪读时间”与“真搞懂、不抄袭”的核心交付。
2. **面向学生（Ward · L2 弱约束可选增强）**：当 Ward 愿意回顾今日学习时，通过底部统一 `VoiceComposer`（路由至 `reflection` 场景）用语音或文字**自由表达今日总结**。系统严格保留孩子原话并提取可验证的六维结构化条目，与客观记录并列对照，帮助孩子建立自我觉察。

> 📌 **重大演进与退役声明**：
> - **已退役**：旧版“强制 2~3 道单选题盲评解锁图表”、“自动生成专注锦囊（`focus_kits`）并强行注入明日计划”、“面向家长的心理说教式亲子沟通话术”均已退役。
> - **严格边界**：Ward 的今日总结属于**主观自述（Self-Review）**，只归属 `Evaluation` 域，**绝不向 `Memory` 投递自述事实，也绝不能单独当成客观学科掌握度或能力画像**。

### 1.2 核心设计原则

1. **零操作兜底交付（报告不依赖自评）**：
   - 家长端的《伴学闭环实况单》与《独立解题凭证》完全由客观证据（`duxue-cam` 行为观测 + `Tutoring` 答疑事实 + `StudySession` 记录）驱动生成。无论 Ward 是否进行课后总结，家长端交付 100% 准时必达。
2. **自由原话优先，拒绝机械问卷**：
   - Ward 总结时不再点选僵硬的“超专注/挺不错”单选题，而是像对学伴聊天一样用语音或文字说几句真实感受；系统整理出的结构化条目必须逐字溯源（`source_quote`）至原话，且允许 Ward 随时修改或删除。
3. **主客观严格分界，去道德评判**：
   - 客观报告只陈述事实（净专注动笔时长、停滞卡壳时段、经几轮启发独立推导出结果），严禁出现“专注度扣分”“说谎”“磨蹭”等道德审判词汇。
   - 主观自述（如孩子说“这道题我彻底懂了”“今天很专注”）明确标注为“Ward 自述”，与客观证据并列展示，不混同为客观结论。

## 二、核心交付物与功能规格

### 2.1 【必达交付】Guardian / Coach 端：《伴学闭环实况单》与《独立解题凭证》

#### 2.1.1 触发与证据版本化（Evidence Versioning）
- **生成时机**：当学习会话完成、或 `duxue-cam` 检测到离座闲置超时自动结算时，后台基于当前已入库的客观证据生成或更新当日报告版本。
- **弱约束兼容**：
  - **有线上计划时**：按已确认的任务名称展示各任务预计用时 vs 实际净专注用时；
  - **无线上计划时（L0 兜底）**：按视觉识别出的物理学习段落（如“学段一 40 分钟”、“学段二 32 分钟”）聚合展示。

#### 2.1.2 《伴学闭环实况单》核心内容（兑现 P0-1 & P0-2）
- **时间与效率账单**：
  - **书桌总驻留时长** vs **有效专注时长**（连续动笔书写、翻页阅读）及**净专注率（%）**；
  - **启动延迟**（从计划时间或落座到真正动笔的耗时）与**中途卡壳唤醒次数**；
  - **家长省心折算**：明确展示“今晚全程 0 次大人催促介入，为您净省 X 分钟陪读时间”。
- **客观行为时间轴**：
  - 横向展示当晚各时段状态分布：`专注读写`、`停滞思考/卡壳`、`答疑互动`、`换书/休息`、`离座`。

#### 2.1.3 《独立解题凭证》核心内容（兑现 P0-3）
针对当晚 Ward 向 AI 提问过的每一道作业题，生成结构化防伪凭证：
- **原题快照与知识点**：提问时的题目图片切片 / 题干摘要及学科知识点标签；
- **卡点诊断与启发轮次**：记录孩子最初卡在哪一步、AI 提供了几轮分步引导（含是否使用结构化配图 `visual`）；
- **独立推导铁证（Proof of Mastery）**：明确记录孩子是否在对话收尾阶段**通过“对话内微验证”独立说出/算出最终关键结果**（或标记为“启发中 / 待问老师”），向家长证明绝非直接抄答案。

#### 2.1.4 Coach（晚托班/督学伴学师）批量交付视图
- 支持关联多名 Ward 的 Coach 在工作台查看全场学员今日的净专注率、高频卡点题汇总，并支持一键向对应家长分发定制化《晚托伴学闭环实况单》。

### 2.2 【可选增强】Ward 端：自由语音/文字今日总结（Reflection）

#### 2.2.1 统一入口与引导（`/companion/turn` -> `reflection`）
- **触发方式**：Ward 在底部 `VoiceComposer` 主动表达回顾意图（如“我来总结一下今天的学习”），或点击今日总结引导入口。
- **上下文温和提示**：当等待 Ward 输入总结时，Companion 参考当天实际发生过的问答主题、已完成任务和用时，给出简短、有正文的自然引导（如：“今天搞定了数学练习册，还自己攻克了鸡兔同笼题！今天整体感觉怎么样，有什么想记下来的吗？”）。

#### 2.2.2 原话保留与六维结构化提取
- **原话不可篡改**：系统保存 Ward 的原始语音转写或文字输入；
- **六维候选提取（模型只出候选，不无中生有）**：
  - 系统从原话中提取最多六个维度的结构化条目（如：成果体感、遇到的困难、觉得有效的方法、情绪状态 `affect`、环境上下文 `context`、下次打算 `next_intent`）；
  - **逐字溯源硬约束**：每个维度的条目必须包含 `source_quote`，且该引用必须**逐字出现在同一版 Ward 原话中**；原话未提及的维度留空，严禁模型脑补。
- **Ward 审阅、确认与乐观锁修订**：
  - Ward 可直接修改总结原话或增删条目，通过 `expected_version` 乐观并发校验保存确认版本；
  - 查询接口始终只返回当前已确认版本，并显式标明为 `Ward 自述`。

#### 2.2.3 主客观对照呈现
- Ward 确认今日总结后，可在界面上并列查看“我的今日原话总结”与“客观专注及答疑时间轴”，直观感知自身体感与客观记录的一致性或偏差。

## 三、领域边界与业务规则（不可违反的不变量）

1. **自述不写 Memory 铁律**：
   - 停止向 `Memory` 投递 `self_review.submitted` 事件，不生成 `daily_review` Episode，也不在 `MemoryBundle` 中复制六维条目；
   - 孩子的自述（“我已经懂了”“这个方法很管用”“下次我要早点写”）不能单独作为客观掌握度、策略有效性或已执行行动的证据。
2. **计划按需读取 `next_intent`**：
   - 系统不自动生成强制“专注锦囊”，也不自动篡改明日计划；仅当 Ward 在制定计划时明确要求参考上次总结时，才按需读取已确认总结中的 `next_intent`。
3. **场景切分边界**：
   - 结合本人今日/近期真实学习经历回顾或谈论以后怎么做 $\rightarrow$ 归属 `reflection`（本模块）；
   - 脱离个人经历的一般性学习方法请教（如“怎么背单词更快”）$\rightarrow$ 归属 `tutoring`（辅导答疑域）。
4. **隐私与数据删除**：
   - 总结原话、修订版本与客观报告严格限制在当前家庭（及授权共管人）范围内访问；账号注销或发起数据清除时，按合规要求物理擦除。

## 四、验收标准

| ID | 验收场景 | 期望结果 | 优先级 |
| :--- | :--- | :--- | :--- |
| **AC-E01** | **零计划/零自评兜底交付** | Ward 未建线上计划、未写今日总结，仅在书桌前写纸质作业并问了 1 道题；会话结束后 Guardian 仍能收到完整的《伴学闭环实况单》与《独立解题凭证》 | P0 |
| **AC-E02** | **Ward 发起今日总结且尚无内容** | Companion 路由至 `reflection`，结合当天任务与答疑主题返回有正文的温和引导，不返回空消息 | P0 |
| **AC-E03** | **六维条目提取与逐字溯源** | Ward 语音输入总结后，模型提取的每个维度条目均包含逐字匹配的 `source_quote`；未提到的维度不生成条目 | P0 |
| **AC-E04** | **总结确认与版本修订** | Ward 修改原话并确认后，按 `expected_version` 更新当前确认版本；并发冲突时返回 `409` | P0 |
| **AC-E05** | **Memory 隔离边界校验** | Ward 提交包含“我彻底学会了分数乘法”的总结后，`Memory` 域不新增掌握度 Claim，答疑域不将其作为已掌握证据 | P0 |
| **AC-E06** | **独立解题凭证生成** | Ward 在答疑引导下独立说出最终得数并通过核验后，当晚报告中准确展示原题、启发轮次与“独立解出”凭证 | P0 |
