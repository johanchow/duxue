# 读学系统：用户核心价值与故事

> 版本 v3.0（2026-11-27） | 关联文档：[产品架构](ARCHITECTURE.md) · [教育通用 Agent PRD](prd-edu-agent.md)

## 一、定义核心价值与商业交付锚点

> 📌 **核心设计原则**：
> 1. **四大核心目标**：**提升孩子专注效率（G1）、引导孩子独立思考与主动探索（G2）、解放家长陪读时间（G3）、赋能教师备课批改与教学生产力（G4）**。
> 2. **零前置负担，强可靠交付**：彻底退场线上计划、任务池与每日复盘自述。孩子坐下直接写纸质作业，系统靠 L0 桌面静默感知 + 统一教育通用 Agent 100% 稳定交付核心价值。
> 3. **双端统一教育通用 Agent**：成人端（Teacher / Coach / Guardian）是全功能教育生产力工作台（备课、动态课件、批改诊断、自验出题）；学生端（Ward）是写作业时严守答案红线的启发伙伴 + 作业外自由画图/编故事/探索的创作伙伴。

### 四类角色的 Jobs-to-be-Done

| 角色 | Job 类型 | 具体诉求 | 读学的硬核可度量交付物 |
| :--- | :--- | :--- | :--- |
| **学生（Ward）** | **提速自由 & 主动探索 Job（G1/G2）** | 我想快点写完纸质作业去玩；卡壳时有人不看脸色搭把手；写完作业后还能和 AI 一起画图、编故事、探索好玩的问题 | **【P0-2】纸质作业提速**（卡壳唤醒 + 可选 Sprint）+ **自由创作探索空间**（画图/故事绘本/互动演示/「我的作品」） |
| **家长（Guardian）** | **省时脱手 & 学业定心 Job（G3）** | 我下班已经很累了，不想坐在书桌旁盯 90 分钟催动笔、讲难题，但又要确认孩子真搞懂了没抄答案 | **【P0-1】《伴学闭环实况单》**（作业专注 vs 自由探索分口径）+ **【P0-3】《独立解题凭证》** + 创作足迹 |
| **教师（Teacher）** | **备课批改与教研提效 Job（G4）** | 我每天花大量时间批改整页作业、找直观的几何/函数动图做课件、出分层变式题还得担心出成错题 | **【P0-4】教师教育通用 Agent 工作台**（整页批改诊断 + 3D/动态交互课件局部修订 + 自验变式出题 + 「我的资源库」） |
| **伴学师（Coach）** | **规模化精细服务 Job（G4）** | 我带 15 个晚托学生，如何在放学时交付 1 对 1 级别的家校日报，同时高效完成批改与共性错题微专题备课？ | **【P0-4】1 人服务 15+ 人的超级伴学工作台**（全场实况 + 教育通用 Agent 批量批改/备课/家校日报） |

## 二、旅程一（Ward 零负担闭环）：线下纸质作业提速 + 作业后自由探索创作

> **场景设定**：小宇（五年级）放学回家，不需要在 App 里建计划、也不需要家长转发作业，直接坐到书桌前摊开纸质《数学练习册》开始写。桌边读学Eye 已启用观察时段。

```text
用户旅程：零计划作业闭环 → 作业后自由创作 → 家长端分口径交付
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【19:10 自动感知开场｜L0 桌面感知底座：零点击进入】
Step 1：小宇坐到书桌前动笔写数学练习册（也可选点「试一轮专注挑战」口述 20 分钟倒计时）
        → 读学Eye 45° 稀疏静音抓拍，自动识别“落座 + 连续动笔书写”

【19:32 遇难题卡壳｜教育通用 Agent（Ward 策略 · 作业启发答疑）】
Step 2：遇到一道“鸡兔同笼变体题”卡壳，小宇拍下题目发给底部 VoiceComposer：“这题不会列式”
        → Agent 识别为作业求助，触发答案保护红线与独立泄露裁判，分步启发 + 自动配图
        → 第 3 轮引导小宇在对话内口算出最终答案“4 只兔子”，后台生成【独立解题凭证】
        → 中途若在 Sprint 期间突然分心说“先帮我画只奥特曼”，Agent 温和提醒：“这轮专注挑战还剩 6 分钟，先搞定手头这一步再来画？”

【20:15 写完纸质作业 → 进入自由探索与创作态】
Step 3：小宇合上练习册，笑着对读学说：“我写完了！和我一起画一个《火星小狗》的三页科幻故事吧”
        → Agent 切换至自由创作 Skill，与小宇一起构思角色并生成带插画的 3 页绘本卡片
        → 小宇语音修改：“把第 2 页的小狗改成戴宇航员头盔的橘猫”，产物局部刷新并存入「我的作品」

【20:45 家长端确定性交付｜林女士收到分口径实况单 + 解题凭证 + 创作足迹】
Step 4：林女士打开手机，看到三个清晰区块：
        - ⏱️《伴学闭环实况单》（严格分口径）：
             桌面观察记录了纸面练习，答疑记录显示孩子尝试用画图解释分数
        - 🛡️《独立解题凭证》：鸡兔同笼变体题，经 3 轮启发由小宇独立推导出结果“4”
        - ✨「好奇心与创作足迹」：作业后共创了一篇 3 页《火星橘猫》科幻绘本（附缩略预览）
```

## 三、旅程二（Teacher / Guardian 教育通用 Agent · G4）：从批改整页作业到动态备课课件与自验出题

> **场景设定**：初中数学张老师（或周末辅导孩子的家长）拿到两页学生刚做完的几何练习卷，需要快速批改诊断错因、把最难的立体几何题做成课堂/讲解用动态课件，再配 2 道巩固变式题（全程无需绑定摄像头或学生设备）。

```text
用户旅程：一句复合指令，打通“批改诊断 → 动态讲题 → 自验巩固”
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【20:00 拍照下达复合目标】
Step 1：林女士在「工作台」顶部关联孩子档案（受权只读），拍下两页手写练习卷并说：
        “帮我批改这两页作业，挑出错题做成动态讲解课件，再结合他这周的薄弱点出 2 道同类巩固题。”

【20:01 自主规划与验证优先执行】
Step 2：教育通用 Agent 透明展示执行进度：
        ① 逐题定位手写步骤并调用 ProblemSolving 确定性核验 → 产出《批改诊断单》
           （第 4、7 题判错并归类错因“辅助线构造遗漏”；第 6 题涂改模糊，诚实标为「待人工复核」）
        ② 针对第 7 题立体几何截面错题，调用 MathStage 生成可旋转拖拽的 3D 动态交互课件
        ③ 只读孩子本周错题特征，生成 2 道分层变式巩固题，并自动自解自验确认条件完备、答案无误

【20:03 局部修订与沉淀资产】
Step 3：林女士觉得课件第 3 步讲得太快，语音说“第 3 步拆细一点，补个生活类比”，Agent 仅重算第 3 步（支持毫秒级 Undo/Redo）；
        满意后点击「保存」存入「我的资源库」，整个过程对孩子的客观 Memory 写入次数为 0。
```

## 四、旅程三（To B2C 第二曲线）：晚托班陈老师如何实现“1 人精细服务 15 名学生”

> **人物与痛点**：陈老师经营社区精品晚托班，每天看管 15 名小学生。过去只能管纪律，放学时向家长交代不清每个孩子的卡点，也没精力为不同孩子单独备课和出巩固卷。

```text
用户旅程：精品晚托班的 L0 感知 + 教育通用 Agent 双重赋能
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【17:00~19:00 晚托执行】
Step 1：每张书桌侧后方部署标准摄像头并共用采集网关；学生各自写纸质作业，80% 常规卡点由 Ward 端启发答疑接住，顽固卡点高亮提醒陈老师精准走到身边辅导。

【19:05 伴学师工作台批量提效】
Step 2：陈老师用成人教育通用 Agent 快速拍照批改班内共性错题，一键生成一份 10 分钟共性错题动态微课课件 + 2 道分层巩固题现场集中讲评。

【19:30 放学交付：15 份媲美“1 对 1 私教”的家校日报】
Step 3：每位家长手机收到专属《晚托伴学闭环实况单》（作业专注与自由探索分口径）+《独立解题凭证》+「创作足迹」，机构专业度与续费率显著跃升。
```
