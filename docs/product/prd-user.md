## 一、文档目标

本文档定义 `duxue-app` 中与用户直接相关的产品能力，包括：

1. 登录前角色选择；
2. Guardian 与 Ward 的登录方式；
3. 登录态与登录方式记录；
4. Guardian-Ward 家庭关系的绑定码关联；
5. Ward 和 Guardian 登录后的首页导航。

本文档不设计通用设备管理能力。除 Ward 主动进入“采集督查”模式外，不包含设备在线状态、电量、网络、存储、故障诊断或远程控制等设备功能。

## 二、产品原则

### 2.1 先选择角色，再完成登录

用户打开 App 后，先声明本次希望以 Ward 或 Guardian 身份进入，再展示对应登录页面。角色选择决定登录后的体验，但不直接授予权限；登录成功后，服务端仍需验证该账号确实拥有所选角色。

### 2.2 同一个 App，两套不同的首页逻辑

- Ward 首页回答：**我今天准备怎么行动？**
- Guardian 首页回答：**孩子最近发生了什么，我怎样才能更好地理解和支持他？**

两端可以使用相同的底层数据，但不能只替换角色名称后复用同一套首页。

### 2.3 Guardian 的核心任务不是“处理待办”

Guardian 使用产品的主要目的依次是：

1. 直接阅读孩子的学习报告，了解发生了什么；
2. 回看引导与孩子的推导，理解思考过程；
3. 根据报告判断是否需要介入；
4. 按需查看历史与长期变化。

家长可先亲自体验启发答疑，再让孩子使用；本期移除作业、通知、留言传递与计划查看，不建立家长待办或决策中心。

### 2.4 采集与交互物理分离

桌面行为观察由标准摄像头与共享采集网关（读学Eye）承担，不内置在 `duxue-app` 的 Ward 端界面中。观察期间须明确采集状态，允许 Ward 现场暂停或结束；Go网关已实现，真实设备/OSS现场验收待完成，见 [采集设计](../technical/design-gateway.md)。

## 三、角色与关系模型

### 3.1 核心对象

| 对象 | 含义 |
|------|------|
| User | 登录系统的自然人账号 |
| Role | 用户本次进入 App 时使用的 Ward 或 Guardian（含共管伴学师 Coach）身份 |
| Family | Guardian 与一个或多个 Ward 所属的家庭/督学空间 |
| Membership | 用户在家庭/空间中的成员身份及权限 |
| Guardian-Ward Relationship | Guardian/Coach 与 Ward 的监护/伴学关系 |
| Login Session | 当前角色、登录方式和有效登录态 |
| Binding Code | Guardian 为 Ward 生成的一次性 6 位数字绑定码 |

### 3.2 角色选择与权限

角色选择是登录意图，不是权限来源。

- 用户选择 Guardian 后，只能进入 Guardian 登录流程；
- 用户选择 Ward 后，只能进入 Ward 登录流程；
- 登录成功后，服务端必须校验账号是否拥有所选角色；
- 校验失败时不得进入对应首页；
- 如果一个账号确实拥有多个角色，可以退出当前角色后重新选择角色登录；
- 不提供在已登录页面中无校验地直接切换权限的能力。

### 3.3 Guardian-Ward 关系、多监护人共管与 B2C 伴学师（Coach）场景

- **1 对多学生管理（赋能家庭多孩与 B2C 晚托班/伴学工作室）**：
  - 一个 Guardian / Coach 账号可以关联多个 Ward（支持 1~100 名学生快速切换与检索）；
  - 在精品晚托班、社区自习室或伴学工作室场景下，伴学老师（Coach）可通过共管授权同时管理班内 10~15+ 名学生，在单一工作台掌握全场学习动态并向对应家长交付日报。
- 一个孩子可以由多位家长共同管理，家庭邀请与权限见[共管成员](#54-家庭共管成员)。
- Guardian / Coach 可以通过孩子列表快速选择当前查看的 Ward；
- Ward 登录后只进入自己的专属空间，不能切换查看其他 Ward。

## 四、登录与登录态

### 4.1 登录前角色选择页

App 冷启动且没有有效登录态时，首先显示角色选择：

```text
欢迎使用读学

你希望以什么身份进入？

[我是孩子]
[我是家长]
```

页面要求：

- 用简单语言说明两种角色的差异；
- 记住用户上一次选择的角色；
- 不展示手机号、生物识别等未支持方式；
- 已存在有效登录态时跳过该页面，直接恢复上次会话。

### 4.2 支持的登录方式

Guardian 使用**邮箱 + 一次性验证码**注册和登录，不设置或输入读学密码。每次登录都需要取得新的邮件验证码；验证码属于单因素邮箱登录，不能表述为双因素认证。

验证码由读学服务端生成并验证，10 分钟有效、仅可使用一次；重发后旧码失效。发送间隔至少 60 秒，每个验证码最多尝试 5 次；服务端还应按邮箱和请求来源限流。只有成功兑换验证码后才发放登录态。邮件送达不能证明持有某台特定设备，不能把邮件验证码当作独立的第二因素。

微信登录作为 Guardian 的后续便捷登录方式，须在微信开放平台的移动应用资质、权限和审核明确可用后接入。已有 Guardian 先通过原账号登录，再主动绑定微信身份；不得凭微信昵称或未验证邮箱自动合并账号。微信接入不改变服务端的 Guardian-Ward 授权关系。iOS 上线前还须核对 App Store 对第三方登录等效选项的要求。

Ward 目前通过 Guardian 发放的一次性绑定码进入；Ward 的其他登录方式需单独设计。当前不提供手机号验证码、游客登录或其他第三方登录。

### 4.3 Guardian 登录

Guardian 选择角色后进入 Guardian 登录页：

```text
家长登录

邮箱
[获取验证码]
6 位验证码
[登录]

[没有账号？注册]
```

注册流程：输入邮箱及显示名称 → 请求邮箱验证码 → 输入验证码 → 创建账号并登录。读学服务端生成并校验验证码；SMTP 服务只负责邮件投递。邮件发送失败或验证码无效时不得创建账号或发放登录态。当前测试账号数据无需迁移。

微信登录获批并实现后，可在此页增加“使用微信登录”；发布前不得展示不可用入口。

首次登录成功后：

1. 如果尚未加入家庭，引导创建家庭；
2. 创建或补充第一个 Ward 档案；
3. 生成 Ward 登录所需的 6 位绑定码；
4. 完成后进入 Guardian 首页。

### 4.4 Ward 登录

Ward 选择角色后进入 Ward 绑定页：

```text
学生登录

家长提供的 6 位绑定码
[绑定并进入]
```

Ward 当前通过 Guardian 发放的一次性绑定码进入学习空间，后续由客户端保存并刷新 Ward 会话；尚无 Ward 用户名密码或微信登录。

### 4.5 登录态记录

登录成功后，客户端记录：

- 当前用户 ID；
- 当前角色；
- 登录方式：Guardian 为 `email_code`，Ward 为 `invite_code`；Guardian 微信接入后可为 `wechat`；
- 当前家庭 ID；
- Guardian 当前选中的 Ward ID；
- 登录时间和最后活跃时间；
- Session/Token 及过期时间。

客户端不得记录：

- 邮箱验证码明文或持久化副本；
- 微信访问凭据明文；
- 可用于绕过服务端鉴权的角色标记。

### 4.6 登录态恢复

- 登录态有效：恢复上次角色并直接进入对应首页；
- 登录态过期：默认展示上次角色及上次使用的登录方式；
- 用户主动退出：清除登录态，但可以保留上次角色和登录方式；
- 服务端撤销会话：客户端收到鉴权失败后返回登录页；
- 当前角色不再有效：说明原因，不得继续展示已缓存的角色数据。

## 五、Guardian-Ward 绑定

### 5.1 Guardian 生成绑定码

Guardian 创建 Ward 档案后，可以生成一个一次性 6 位数字绑定码。绑定码关联：

- 当前家庭；
- 对应 Ward 档案；
- 发起 Guardian；
- 有效期限；
- 单次使用状态。

示例：

```text
孩子加入码

482731

请让孩子在登录页输入此绑定码
```

绑定码短时有效、仅能成功使用一次；应限制连续输错次数与请求频率，避免被批量猜测。

### 5.2 Ward 输入绑定码

Ward 在登录前选择“我是孩子”，进入学生登录页后输入 Guardian 提供的 6 位绑定码。

匹配成功后显示：

```text
你将加入：

家庭：小宇的家庭
家长：林女士
你的档案：小宇

[确认加入]
[取消]
```

Ward 确认后：

1. 建立 Ward 账号与 Ward 档案的关联；
2. 建立家庭成员关系；
3. 建立 Guardian-Ward 关系；
4. 使绑定码失效；
5. 完成登录并进入 Ward 首页。

### 5.3 异常处理

- 绑定码错误：提示检查后重试；
- 绑定码过期：提示 Guardian 重新生成；
- 绑定码已使用：不得重复建立关系；
- 连续输错达到限制：短暂禁止继续尝试；
- Ward 已绑定其他家庭：阻止自动覆盖；
- 登录账号角色不匹配：阻止绑定；
- 用户取消：不创建任何关系。

### 5.4 家庭共管成员

- 在「我的 → 共管成员」选择一个孩子，填写另一位家长的登录邮箱。邀请 24 小时有效，对方使用该邮箱登录后在同一页面确认。确认后，该孩子出现在对方的孩子列表。
- 两位家长共享同一份孩子档案，都能查看学习情况和报告、修改姓名和学段、管理学生 App 绑定及学习设备。每个孩子单独发起邀请。
- 档案创建者可取消待确认的邀请、移除成员和清除孩子数据。受邀人可主动退出。移除或退出后，服务端立即停止向该账号授权该孩子的数据。

## 六、Ward 首页与导航架构（默认安静首页 + 统一教育 Agent + 可选专注挑战）

Ward 首页优先帮助孩子回到线下作业：默认安静，不自动展开历史对话、弹键盘、或堆砌娱乐创作广场与推荐流；底部复用既有唯一 `VoiceComposer`，保留 ASR 与拍照结构，统一承接**作业启发答疑**与**自由创作探索（画图、故事绘本、互动演示、知识卡片）**。原线上计划、作业任务池与今日总结复盘已正式退场。

### 6.1 默认主界面

```text
┌────────────────────────────────────────────┐
│ 读学                                  [⋯] │
│                                            │
│          先做手边的一小步                  │
│          有问题，随时找我。                │
│                                            │
│         [试一轮专注挑战]                   │
│                                            │
│       原有 VoiceComposer：ASR＋拍照         │
└────────────────────────────────────────────┘
```

“新建对话 / 历史对话 / 专注挑战 / 我的作品”收在右上更多菜单（不再提供“作业/计划”或“今日总结”入口）。**默认进入最近活跃的 1 个对话**，不铺满复杂聊天列表；按需可新建独立对话隔离作业答疑与不同创作主题，或在历史对话列表中切换、删除单条对话。首页不放“继续上次对话”按钮；主动输入时续接当前默认对话。相机直接打开，取消不弹对话；选好图片后保留原暂存、上传与发送步骤。普通主动提问/创作或查看历史才展开对话，可主动收起；收起不清线程、草稿、历史或在途请求，迟到回复不重新弹起。回到前台不擅自展开对话。

### 6.2 专注挑战：口述、只读确认、明确开始

点击“试一轮专注挑战”后，首页提示“这轮想做什么，试多久？说给我听”，继续使用同一个底部 ASR，不弹主题/分钟填写框，也不自动开始录音。

- 说“数学，先试二十分钟”：整理为只读 `数学 · 20分钟`，提供 `[开始本轮] [重新说]`。
- 只说“二十分钟”：整理为 `专注挑战 · 20分钟`，不追问主题。
- 只说“写数学”：只问“想试多久？”，下一句口述保留本轮明确主题；纠正以新口述为准，不要求重复全部内容。
- 重新说用于口述修正；右上角关闭图标（操作提示“取消专注挑战”）或明确口述取消都能返回安静首页。取消后，迟到 ASR/整理结果不能变成普通聊天或重新弹确认。
- 整理阶段不创建学习会话或挑战，不修改正在进行的对话；合法时长且孩子点击“开始本轮”后才计时。语音识别/模型/开始失败可重试，不补默认 20/30 分钟。

只有本人主动开始、实际起点和正时长齐全的 Sprint 才显示限时卡，支持暂停、继续、结束本轮和收起。主题是本轮口述标签；到时只结束本轮计时，不代表作业完成或成功专注。已有 active/paused 轮次重新打开时恢复本轮，不重复开新轮。完整时间与运行语义归 [主动专注挑战 PRD](prd-schedule.md)。

### 6.3 统一教育 Agent（Ward 策略）与专注态软边界

返回首页时默认展示尚在进行或暂停的挑战：从成长/我的切回首页、收起对话，以及恢复 App 前台时，清除本次临时收起状态并查询当前轮次；已结束的挑战不恢复。卡片收起只影响当前查看，不暂停或结束计时。

“试一轮专注挑战”入口使用表达认真投入的小火焰图标。挑战倒计时只显示一处：卡片展开时只在卡片内显示；卡片收起后，首页与对话顶部的时钟图标下方显示小号分秒倒计时。暂停时标明暂停并冻结，到时或结束后移除倒计时。点击时钟可重新展开当前挑战，同时隐藏顶部数字。

对话界面提供安静的专注挑战图标，复用同一 ASR 与独立只读预览；取消或开始后保留原对话、草稿与原上下文，不跳回首页。收起对话同时取消未确认的预览，迟到结果不重开。

- **底部 `VoiceComposer` 统一承接 Ward 端教育通用 Agent**：
  - 作业/解题求助：走受保护启发答疑（严守答案保护与独立泄露裁判），保留原 LaTeX、配图、发音与看图；
  - 自由创作与探索：支持画图、故事绘本共创、知识卡片与数理互动演示，交付可语音局部修改与 Undo/Redo 的轻量产物，并可存入右上角「我的作品」；
  - **专注态软边界与作业防代写**：在 Sprint 进行中或存在未完成作业题期间发起偏题娱乐创作时先温和提醒专注；识别为课内作文/作业时强制走启发共创、禁止代写成品。详细规则见 [教育通用 Agent PRD §四](prd-edu-agent.md#四ward-端需求目标mvp-闭环)。
- 新建、切换或删除对话仅影响对应对话的短期上下文与可见列表，**绝不删除**已保存作品、教学事实、长期记忆，也不能借此重置正在进行的 Sprint 专注态。

## 七、Guardian / Teacher / Coach 成人端导航

成人端面向两类互补诉求：一是**家长（Guardian）每晚高效查收确定性的伴学汇总结果、解放陪读时间（G3）**；二是**教师/伴学师（Teacher / Coach）与家长借助教育通用 Agent 工作台高效完成备课、批改、动态课件制作与变式出题（G4）**。

### 7.1 孩子首页：晚间客观汇总报告直接呈现

默认进入「孩子」，底部导航为「孩子 / 工作台（原问答） / 我的」。单孩子直接显示其晚间汇总报告；多孩子先显示列表，点击孩子即直接阅读报告与解题记录，保留全局导航，可返回全部孩子。孩子设置收在右上角。

晚间汇总报告完全由客观过程证据（L0 读学Eye 桌面视觉 + `Tutoring` 作业启发事实 + Ward 自由创作足迹）驱动，**不依赖线上计划、打卡或孩子每日总结**，正文直接包含三个客观内容区：

1. **《伴学闭环实况单》直接展开（严格分口径）**：
   - 显示所选孩子、所选日期的客观观察汇总与物理学习段落；
   - **「线下作业净专注时长」与「AI 自由探索/创作时长」严格分口径呈现**，绝不将自由画图/编故事时间混算进有效作业时长；
   - 主动专注挑战（Sprint）计时独立记录，缺少桌面视觉证据时不冒充有效专注时长；缺失采集证据如实标明覆盖范围，不做道德评判或制造额外待办。
2. **《独立解题凭证》**：
   - 展示当晚作业答疑中存在可靠逐题引导与孩子实质尝试的题目，可就地展开原题、引导过程与对话内微验证推导记录；
   - 不显示几份几次，不把“提交答案”或“我懂了”当作已通过核验；发音、闲聊、自由创作与安全失败不进入凭证；没有凭证时不占位，报告尚未生成也不阻塞已有凭证。
3. **「好奇心与创作足迹」**：
   - 轻量汇总孩子当天主动探索的非作业主题与保存的创意作品缩略预览，让家长看见作业之外的思考活力（仅作兴趣足迹，不混入学业掌握度；无创作时不占位）。

多孩子可返回列表选择另一位，通过安静的「历史」日期入口查阅往日；下拉刷新及回到前台重新读取。切换孩子、日期时，不展示另一孩子或另一日期的旧内容。

**未生成与异常状态**：没有当日报告时显示“报告尚未生成”，正在处理显示“正在整理学习报告”；加载失败单独显示错误与重试，不伪装成没有记录，也不编造报告。凭证与足迹失败只影响各自区块。

### 7.2 成人教育 Agent 工作台与体验

「工作台」（由原「问答」Tab 演进）面向**学科老师、教培老师、伴学师（Teacher / Coach）**与**家长（Guardian）**，无需先绑定孩子即可直接使用（支持文字、语音、单张/多张拍照与连续对话修订，协议与未来 Web 教师工作台同源）。完整能力规格唯一归属 [教育通用 Agent PRD §三](prd-edu-agent.md#三teacher--coach--guardian-成人端需求目标mvp-闭环)。

提供两种严格隔离的成人模式：
1. **教育通用 Agent 工作台（默认 · 成人策略）**：
   - **默认 1 个当前工作对话 + 按需多对话管理**：顶部提供「新建对话 / 历史对话」入口，支持按任务隔离多个持久化对话（例如对话 A 批改几何卷、对话 B 备课分数除法），重启 App 或重新登录后保留历史对话与切换能力；
   - 支持一句话下达单一或复合教育目标：整页/多页**作业拍照批改与错因诊断**（手写模糊或低置信显式标「待人工复核」）、**深度讲题与动态交互课件**（承接 `MathStage` 与局部修订）、**备课教案与变式出题**（新出题目先自解自验再交付）；
   - **受权只读关联学生上下文（按对话独立绑定）**：每个工作对话顶部均可选显式关联某位已绑定 Ward，只读其近期卡点与实况报告生成针对性讲义、巩固题或家校沟通简报；**绝不隐式写回**孩子客观 `Memory` 或 `TutoringSession`；
   - **主动保存与「我的资源库」**（升级原「我的课件」）：所有产物默认临时、支持主动保存至顶部「我的资源库」，统一管理动态课件、批改诊断单与教案/变式卷，支持按类型筛选、重命名、删除、冷启动同 ID 重开继续局部修订与 Undo/Redo；删除对话不影响已保存产物。
2. **体验孩子怎么学（`student_guide`）**：与孩子实际使用的苏格拉底式启发答疑完全一致，遵守相同的答案保护红线与独立审核，便于家长在让孩子使用前亲自体验启发效果；支持一键转入成人工作台查看同一题的完整讲解。

两种模式均遵守内容安全护栏，与孩子的真实对话、报告、解题凭证及记忆写入完全隔离。家长可在「孩子」页添加孩子或获取学生绑定码；当天报告与凭证均为空时，孩子页提供「先试一下工作台」与「让孩子开始使用」。

原作业传递、通知、留言传递、计划查看及每日自述入口均已正式退役。
