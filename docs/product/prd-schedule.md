## 一、定位与原则

Plan / Task 帮孩子记住作业、选择眼前一步、在中断后继续，并在需要时检查剩余事项。它是 L2 可选增强，不以登记任务、估时、点击开始或标记完成作为观察、答疑和晚间报告的前置条件。

**Task 帮忙记事，Plan 帮忙梳理顺序与约定，Sprint 是孩子主动选择的一段专注挑战。**后台保留有依据的状态与时间；普通任务不常驻首页，不假设孩子仍在做某项或已进入下一项。“一句话点火”是辅助入口，不要求孩子维护任务管理系统。

- 默认首页不展示当前项、下一项、任务进度或完成按钮；普通计划与已知作业仅在询问、确认卡或主动查看时呈现。
- 只说明干什么就能登记、安排；预计时长和开始钟点均可选，不为补齐这些字段而追问。
- 只有 Ward 明确开启、具有实际开始时间和目标持续时间的 Sprint 才显示限时挑战卡；普通任务即使有开始时间和预估时长也不自动变成挑战。
- 普通任务的开始、暂停、继续、完成仍可在详情或对话中操作，不常驻首页，不强制逐项点击留痕。
- Guardian / Coach 可传递作业，Ward 保有安排与确认权；未选入本轮的任务无需说明原因。
- 视觉观察有证据和能力边界，不因保留状态模型而自动填满状态。观察能力进度与事实边界见 [Behavior 设计](../technical/domain-behavior.md)。

## 二、有价值的用户场景

| 场景 | 用户故事 | 价值 |
|---|---|---|
| 容易开始 | 小宇问“先做什么”，选择数学后回到纸面；系统不持续展示数学或追问进度 | 给出建议后安静退场 |
| 帮忙记事 | 妈妈转发作业，小宇问“今天还有什么”，按需查看全部已知事项 | 减少遗漏和家长反复提醒 |
| 灵活换项 | 数学卡住，小宇说“先读英语，数学待会儿继续” | 保留未完成项，避免一处卡壳拖住整晚 |
| 专注挑战 | 小宇主动选择“专心写二十分钟数学”，开始后显示限时卡，到时询问继续或休息 | 提供可控的短时投入，不要求整项作业完成 |
| 可选估时 | 小宇主动估计数学20分钟，收工后主动查看同口径的实际记录 | 帮助建立时间感，不增加开始门槛 |
| 自主收尾 | 小宇问“还有没做的吗”，系统列出尚未确认完成的已知作业 | 帮孩子自己核对，不要求家长逐项催促 |

## 三、前台展示与入口

### 3.1 默认首页与专注挑战卡

普通计划无论是否登记了开始时间、预估时长或显式会话，均不常驻展示“当前任务/下一项”。首页以对话流和 `VoiceComposer` 为主，可保留“作业 / 专注挑战”的安静入口，不展开任务与进度。

只有孩子明确开启的 Sprint 在本轮有效期内展示，例如：

```text
数学 · 二十分钟专注挑战       [暂停] [结束本轮]
剩余 12 分钟                 [收起]
```

卡片显示的是这轮挑战及计时，不是系统认定孩子仍在做数学，不标注“已专注12分钟”。不展示下一项或默认“写完了”按钮。收起仅隐藏卡片，不暂停计时；可由静态入口或主动询问恢复查看。

| 情况 | 首页表现 |
|---|---|
| 普通任务无时间 / 仅有起点 / 仅有预估时长 | 不展示任务条，询问或详情中按需查看 |
| 普通任务起点与预估时长齐全，甚至已有显式开始记录 | 仍不展示，不自动转为 Sprint |
| 已确认未来挑战，但尚未明确开始 | 不常驻挑战卡；可按约定给一次开始邀请，到点不自动开始 |
| 已主动开始，实际开始时间与目标持续时间齐全 | 显示本轮挑战卡与暂停/结束操作，允许收起 |
| 本轮显式暂停 | 卡片可显示暂停与继续，不计暂停时长、不自动恢复 |
| 本轮到时、提前结束或取消 | 移除挑战卡，恢复默认首页；不显示下一任务，不据此标任务完成 |
| 恢复 App 后状态未核实 | 不以旧缓存继续展示运行中挑战；查询当前版本后再决定显隐 |

Sprint 的开始、计时与到时规则见 §4.4。普通任务状态长期未更新时保持“尚未确认”，不要求孩子为了界面准确而持续打卡。

### 3.2 今日已知作业

“今天的作业”入口或“还有什么”对话可展示全部已知事项，包括未选入当前计划、已安排和已完成项；可查看来源、改顺序、移出本轮或取消误建任务。默认不展开任务池、欠账列表或复杂时间轴。

家长传递的信息保留来源，不只取前两三项后丢弃其余作业。解析不明确的内容保留待确认，不自动补造作业或时长。常做学科仅是建议，不代表今天确有该项作业。未完成状态表示尚未确认完成，不足以断言孩子没做。收工核对只响应孩子主动请求，不因剩余项阻断离开或报告。

### 3.3 自然语言与快捷操作

- “先写数学，再读英语”：整理名称与顺序，确认后保存，无需估时或精确钟点。
- “七点先数学四十分钟，再英语”：按普通安排保留起点、预估与顺序；确认卡可显示，确认后不常驻首页，也不默认开启挑战。
- “我想专心写二十分钟数学”：展示 Sprint 开始卡，孩子点 `[开始这次挑战]` 才启动；若明确说“现在开始二十分钟数学挑战”，可按明确开始命令执行，无需重复确认。
- 快捷按钮区分 `[先做数学]`（安排）与 `[开始数学]`（安排并请求开始）。按钮含义明确时点击即可完成相应授权，无需重复确认。
- 自然语言安排整理成轻量确认卡；明确的开始、暂停、继续、换项、完成表达由对应执行用例承接。对象不明确时只澄清必要目标，不要求补齐可选字段。
- “我现在开始数学”记录本次收到的开始声明，不反推更早的动笔时间；“今晚先做数学”只记录安排。

### 3.4 主动引导的边界

默认以安静入口和孩子主动表达为主。落座邀请和答疑收尾建议为后续可选增强，不能作为基础体验前提：

- 只有观察证据新鲜且具备可触达通道时，才考虑落座邀请；无证据不得说“看到你坐下了”。
- 已在学习或答疑时不插话；答疑结束默认让孩子回到纸面，不必每次再立目标。
- 一次邀请被忽略或拒绝后，当晚不再通过其他入口主动追问计划；静态入口仍可使用。
- 可以在合适时机低频建议“要不要试一轮专注挑战”，必须可忽略，不自动开启。没有计划、未打开 App 或未回应邀请，均不视为学习异常，也不向家长催办。

## 四、执行与时间语义

### 4.1 安排、开始、完成分开记录

确认计划只代表准备做；实际开始需显式开始命令或明确的当前开始表达。点击标明“开始”的按钮可以合并安排与开始授权，但两类事实仍分别记录。

任务状态由 Planning 管，进行中和暂停由 StudySession 管；具体状态机、幂等和跨域事务边界见 [领域设计](../technical/domain-planning.md)。没有可靠来源时，开始时间、持续时间或完成情况允许为空。视觉只提供可见活动，不自动开启/完成某项任务；离座、换书和预计时长到点都不等于完成。

### 4.2 中断、换项与顺序

| 用户表达 | 业务含义 |
|---|---|
| 先停一下 / 继续 | 暂停或恢复显式会话，保留任务 |
| 先做英语，数学待会儿继续 | 暂停当前会话，保留数学未完成；明确要现在开始时再开启英语会话 |
| 今天先做到这里 | 结束本次执行，不把未完成任务标为完成 |
| 数学写完了 | 记录 Ward 声明完成，不能声称系统验证了作业质量 |
| 英语放后面 | 修改未开始项的顺序，不改写已有执行事实 |

后续任务仅在用户询问或主动操作时供其承接，不因上一项的状态自动显示下一项，不按前一项的预计时长自动开始或催下一项。只有用户明确约定的钟点才参与 `StartCue`；它只邀请，不自动开课。跨日保留历史与未完成事项，不默认展开“昨日欠账”，也不把跨日当完成。

### 4.3 估时与回顾（可选）

用户未报估时就保留为空，不自动填30分钟。区分“预计四十分钟完成”与“先做二十分钟”：后者是投入时段，时段结束不等于任务完成。系统建议被接受时，保留建议来源，不当作孩子独立估时。

默认不自动弹出估时纠偏、效率评分或强制结算。孩子主动问、进入详情或选择复盘时，按以下口径呈现：

- 预计完成耗时，对照相同任务范围内、有可靠开始与完成记录的经过时间；暂停区间可单列。
- 显式会话累计计时按会话区间计算；不把它称为净专注或净动笔时长。
- 视觉活动、阅读、静止及缺口单列并标注覆盖，不用净书写时长替代完成耗时，不将停笔判为卡壳或低效。
- 未确认完成、范围变化或记录缺失时，不计算估时准确度。历史建议仅在用户需要、任务范围与时间口径可比时提供，不覆写原估时、不阻塞开始。

### 4.4 专注挑战（Sprint）

- **开启条件**：Ward 明确选择挑战并授权开始，实际 `started_at` 与正的 `target_duration_minutes` 均已确定。“现在开始”由服务端记录实际起点；时长缺失只在这条主动挑战路径中轻量补问，普通任务不受此门槛影响。Guardian 与 AI 不可代开。
- **意图分开**：“预计二十分钟写完”是完成估计；“挑战专心做二十分钟”是投入承诺。系统建议或计划时间齐全都不能代替挑战授权。挑战可关联 Task，也可只给出“阅读”等主题，不要求先创建整晚计划。
- **计时**：目标为本轮累计运行时长，显式暂停期间不累计；继续需用户明确操作。运行时长只证明挑战计时经过，不证明持续专注，视觉活动另列。关闭/收起卡片、息屏与断网不重置计时；重连以服务端已确认起点、区间和版本恢复，不宣称未确认的暂停已生效。
- **到时**：结束本轮挑战计时并移除卡片，最多在回复安全点给一次非阻断提示“这轮结束了，要继续还是休息？”。不插入答疑半轮，不后台反复通知；晚到的提示不强制补弹。跨本地日结束遗留挑战，不恢复旧卡或自动重开。到时不自动完成 Task，不自动结束原有 StudySession，不自动开下一项。
- **后续**：“再来一轮”由孩子明确开启新一轮；“提前结束”不算失败；“作业写完了”另走明确完成命令，不能把结束挑战等同于完成作业。
- **记录**：挑战记录区分约定、开始、暂停、到时和提前结束；没有观察证据时，只能说“这轮计时二十分钟”，不能说“成功专注二十分钟”。

## 五、非目标与验证方式

不做跨周复杂排期、强制起止钟点、必做未安排原因门禁、普通任务常驻倒计时、超时告警、自动将观察归为任务完成、Guardian 代替 Ward 确认。

产品验证关注启动负担、家长催促次数、遗漏与打扰反馈，以及孩子是否愿意再次主动开启 Sprint、是否有助于开始学习；不把挑战到时率当作专注成功率，计划创建率、按钮点击率仅作辅助。孩子不使用计划而直接开始学习也可视为成功。以下是目标验收，不代表当前代码已满足。

| AC-016 | Sprint 缺少观察证据 | 不声称“成功专注”，不将计时或到时当作专注/作业完成证据 | P0 |
