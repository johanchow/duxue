## 一、定位与原则

**Sprint 是孩子主动选择的一段短时投入计时挑战**，用于帮孩子降低纸质作业启动阻力、保护心流。它是完全可选的轻量工具，不作为观察、答疑、自由探索或晚间报告的前置条件。

- **自愿开启，零前置负担**：不要求先建任务或排计划；孩子想试一轮专注计时时，一句话口述即可开始，不想用时直接写纸质作业或找 AI 提问。
- **独立于作业完成与专注证明**：到时只代表本轮计时结束，**不等于作业写完，也不等于系统验证了有效专注**（有效专注以 L0 读学Eye 客观视觉证据为准）。
- **联动专注态软边界**：Sprint 进行中时，系统判定 Ward 处于**专注态**，教育通用 Agent 不会主动诱导娱乐创作，遇偏题创作请求先温和提醒专注（详见 [教育通用 Agent PRD §4.4](prd-edu-agent.md#44-两大核心护栏作业代写防线--专注态软边界)）。

## 二、前台展示与口述交互

首页与口述交互的唯一 UI 规则见 [用户 PRD §6.2](prd-user.md#62-专注挑战口述只读确认明确开始)。只有孩子明确开启、且实际开始时间与目标持续时间齐全的 Sprint 才显示限时挑战卡：

```text
数学 · 二十分钟专注挑战       [暂停] [结束本轮]
剩余 12 分钟                 [收起]
```

| 情况 | 首页与对话表现 |
| :--- | :--- |
| 未开启 Sprint | 默认安静首页，无常驻计时条 |
| 已主动开始，实际起点与正时长齐全 | 显示本轮挑战卡与暂停/结束操作，允许收起（收起后顶部时钟显示小号倒计时） |
| 本轮显式暂停 | 卡片显示暂停与继续，暂停期间不累计运行时长、不自动恢复 |
| 本轮到时、提前结束或取消 | 移除挑战卡，恢复安静首页；不评价失败，不自动重开 |
| 恢复 App 后状态未核实 | 不以旧缓存继续展示运行中挑战；查询服务端当前版本后再决定显隐 |

## 三、专注挑战（Sprint）核心规则

1. **开启条件**：Ward 明确选择挑战并授权开始，实际 `started_at` 与正的 `target_duration_minutes` 均已确定。时长缺失时仅在这条主动挑战路径中轻量补问一句“想试多久？”，不自动补默认 20/30 分钟。Guardian 与 AI 不可代开。
2. **计时语义**：目标为本轮累计运行时长，显式暂停期间不累计；继续需用户明确操作。关闭/收起卡片、息屏与断网不重置计时；重连以服务端已确认起点、区间和版本恢复。
3. **到时行为**：结束本轮挑战计时并移除卡片，最多在回复安全点给一次非阻断提示“这轮结束了，要继续还是休息？”。不插入答疑半轮，不后台反复通知；跨本地日自动结束遗留挑战，不恢复旧卡。
4. **后续与记录**：
   - “再来一轮”由孩子明确开启新一轮；“提前结束”不算失败；
   - 挑战记录区分开始、暂停、到时和提前结束；没有桌面观察证据时，只能说“这轮计时二十分钟”，不能声称“成功专注二十分钟”。
5. **观察主动邀请的边界（后续可选增强）**：
   - 只有桌面观察证据新鲜且具备可触达通道时，才可在卡壳超时后温和递梯子或低频建议“要不要试一轮专注挑战”；已在答疑时不插话，忽略或拒绝后当晚不重复追问。

## 四、验收标准

| ID | 场景 | 期望结果 | 优先级 |
| :--- | :--- | :--- | :--- |
| **AC-S01** | **不使用 Sprint 直接学习** | 不阻断桌面观察、作业启发答疑、自由创作与晚间报告交付 | P0 |
| **AC-S02** | **口述开启 Sprint** | 明确授权、实际起点与目标时长均具备后才展示挑战卡；取消后迟到结果不误开挑战 | P0 |
| **AC-S03** | **暂停/继续、收起与断网恢复** | 暂停不累计；收起不暂停；按服务端区间与版本恢复，重复开始不产生并行挑战 | P0 |
| **AC-S04** | **到时或提前结束** | 移除挑战卡，不评价失败、不打断答疑半轮、不自动重开 | P0 |
| **AC-S05** | **专注态软边界联动** | Sprint 进行中发起偏题娱乐创作时，教育通用 Agent 先给出温和专注提醒 | P0 |
| **AC-S06** | **缺少观察证据时的口径** | 不声称“成功专注”，不将计时或到时当作客观有效专注时长 | P0 |
