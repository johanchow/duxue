# 读学系统 — 产品需求文档与用户手册

> 版本 v1.0 | 本文档面向产品设计、运营及终端用户，描述系统核心需求背景与摄像设备的接入操作指南。

---

## 一、产品概述

读学系统是一款基于 AI 视觉分析的行为观察平台。**guardian（监护人）** 通过架设摄像设备，对 **ward（被监护者）** 的状态进行持续记录与分析，系统自动生成行为报告供 guardian 查阅。

### 核心角色

| 角色 | 说明 |
|------|------|
| **guardian（监护人）** | 注册并使用系统的人，可以是家长、老师、机构管理员等。负责创建 ward 档案、配置分析规则、查看报告。 |
| **ward（被监护者）** | 被观察的对象，可以是孩子、学员等。无需注册账号，由 guardian 创建和管理。 |
| **摄像设备** | 绑定到 ward 的摄像端，负责将画面实时推送到系统。可以是旧 Android 手机、IP 摄像头等。 |

> 系统不限定使用场景，guardian 与 ward 的关系可以是亲子、师生、机构与学员等任意监护场景。

---

## 二、核心需求

### 2.1 为什么需要摄像采集

系统的第一步是获取 ward 所在场景的图片帧，用于：

1. **实时分析**：将摄像画面按固定间隔截帧，逐帧分析 ward 的行为状态，生成时间轴与统计报告
2. **数据积累**：长期记录为 guardian 提供趋势对比，发现行为规律

系统对图片的最低要求：

| 维度 | 要求 |
|------|------|
| 格式 | JPG / PNG / WebP |
| 分辨率 | 短边 ≥ 320px，长边 ≤ 1280px |
| 内容 | ward 清晰可见，无严重过曝或遮挡 |
| 来源 | 不限，任何能拍到 ward 所在场景的设备均可 |

### 2.2 隐私要求

ward 的视频属于敏感数据。系统提供两类接入模式，guardian 可根据自身合规要求选择：

| 模式 | 说明 | 适用摄像方案 |
|------|------|------------|
| **自有服务器模式** | 视频/图片帧只传输到 guardian 所在机构自己部署的读学服务器（阿里云/腾讯云等），不经过任何第三方摄像厂商的云服务 | 方案 A（Android 手机）、方案 B（IP 摄像头） |
| **厂商云模式** | 视频流经过摄像厂商的云服务器（guardian 已接受其隐私条款） | 方案 C（萤石摄像头） |

## 三、摄像设备方案选择

| 方案 | 硬件成本 | 是否需要电脑常开 | 是否经过厂商云 | 推荐度 |
|------|---------|--------------|-------------|--------|
| **A. 闲置 Android 手机** | 0（已有） | 不需要 | 不经过 | ⭐⭐⭐⭐⭐ |
| **B. 专业 IP 摄像头** | ¥150~300 | 不需要 | 不经过 | ⭐⭐⭐⭐ |
| **C. 萤石摄像头（开放平台）** | ¥100~200 | 不需要 | 经过萤石云 | ⭐⭐⭐ |
| D. USB 摄像头（罗技 C270 等） | ¥100~350 | 需要 | 不经过 | ⭐⭐ |
| E. 自制 ESP32-CAM | ¥30~50 | 不需要 | 不经过 | ⭐⭐（需硬件开发） |

**如何选择：**

- 家里/机构有闲置 Android 手机 → **直接用方案 A，零成本**
- 无闲置手机，希望稳定无人值守部署 → **方案 B**
- 已有萤石摄像头且接受云端传输 → **方案 C**

## 四、方案 A：Android 手机（最推荐）

### 原理

将一台闲置 Android 手机架设在 ward 场景附近，安装**读学Eye**（Cam App）后，手机通过网络向读学服务器推送 RTMP 视频流，服务器定时截帧并进行 AI 分析。视频数据只传输到机构自己部署的读学服务器，不经过任何摄像厂商的云服务。

### 所需材料

- 闲置 Android 手机一部（Android 6.0 及以上）
- 手机支架或固定架（使摄像头朝向 ward，¥10~30）
- USB 充电器（长期插电工作）
- 可以连接互联网的 WiFi 网络

### 操作步骤

**第一步：Guardian 在读学 App 中生成邀请码**

1. 打开读学 App，进入 ward 的档案页
2. 点击"添加摄像设备"
3. 系统生成一个 6 位邀请码和对应二维码（有效期内一次性使用）

**第二步：在手机上安装读学Eye（Cam App）**

在 Android 手机上安装**读学Eye**（应用商店搜索"读学Eye"，或扫描运营方提供的安装二维码下载）。

**第三步：关闭电池优化**

为确保 App 在后台长期稳定运行：

```
手机设置 → 电池 → 找到"读学Eye"App
→ 将电池优化设置为"无限制"或"不限制"
→ 同时开启"自启动"权限
```

**第四步：输入邀请码完成绑定**

1. 打开读学Eye，点击"扫码绑定"扫描第一步生成的二维码（或手动输入 6 位邀请码）
2. 绑定成功后，App 会显示已关联的 ward 名称

**第五步：开始推流**

绑定完成后，读学Eye 会自动获取推流地址，点击"开始监控"即可开始向服务器推送视频流。

### 注意事项

- **供电**：手机必须插着充电器运行，长期推流+WiFi 传输非常耗电
- **网络**：手机需要能访问互联网（连接 WiFi 即可，无需与服务器同一局域网）
- **锁屏**：读学Eye 支持锁屏后后台推流，但需确保已完成第三步的电池优化设置
- **iOS 不适用**：iPhone/iPad 系统限制后台摄像头访问，不适合长期挂机使用

## 五、方案 B：专业 IP 摄像头

### 适用场景

需要更稳定、无人值守的长期部署，或需要在没有闲置手机的场所使用。

### 推荐硬件

| 型号 | 价格 | 说明 |
|------|------|------|
| 海康威视 DS-2CD 系列（工程款） | ¥150~300 | 支持 ONVIF 协议，可彻底关闭云功能 |
| 大华 DH-IPC 系列 | ¥150~300 | 同类，企业级稳定性 |
| Reolink 系列 | ¥150~250 | 支持 RTMP 推送到自定义服务器 |

> **重要**：务必选"工程款/网络摄像头（NVR 用）"，而非"智能家居摄像头"（萤石/小米消费款）。消费款的云同步功能难以彻底关闭，无法满足自有服务器模式的隐私要求。

### 操作步骤

**第一步：购买并开箱**

确认摄像头支持 RTMP 推流或 RTSP 拉流协议（产品参数页通常有注明）。

**第二步：连接网络**

通过网线或 WiFi 将摄像头接入可以连接互联网的网络。

**第三步：进入摄像头后台，配置推流地址**

在摄像头的 Web 管理界面中找到"推流设置"或"视频输出"，填入读学服务器的推流地址（在读学 Admin 后台的设备管理页面可查到）：

```
推流地址 → rtmp://读学服务器域名/live/{stream_key}
```

**第四步：关闭云同步（隐私保护）**

在摄像头设置中，关闭所有云存储、远程访问相关功能，并通过路由器确认摄像头没有主动对外联网流量。

**第五步：在读学系统中绑定设备**

与方案 A 的第五步相同，在读学 App 中为 ward 生成绑定二维码，完成设备绑定。

## 六、方案 C：萤石摄像头（经萤石开放平台）

### 适用场景

guardian 已有萤石品牌摄像头，且接受视频流经过海康/萤石云服务器（知名大厂，guardian 已接受其隐私条款）。

### 前置条件

1. 前往 [萤石开放平台](https://open.ys7.com) 注册开发者账号
2. 创建应用，获取 `AppKey` 和 `AppSecret`
3. 摄像头需绑定到该应用下（通过设备序列号+验证码）
4. 在萤石 App 的设备设置中**关闭视频加密**，否则拉流时需要额外传入验证码

### 操作步骤

**第一步：获取萤石开发者凭证**

登录萤石开放平台 → 创建应用 → 记录 AppKey 和 AppSecret。

**第二步：将摄像头绑定到应用**

在萤石开放平台控制台，通过设备序列号和验证码将摄像头关联到你的应用。

**第三步：在读学系统后台填入凭证**

进入读学 Admin 后台 → 摄像接入配置 → 填入 AppKey、AppSecret 和设备序列号。

**第四步：在读学系统中绑定设备**

与方案 A 的第五步相同，在读学 App 中为 ward 生成绑定二维码，完成设备绑定。

### 注意事项

- accessToken 有效期约 7 天，系统会自动刷新，无需手动操作
- 查看历史录像需要购买萤石云存储增值服务（额外付费）
- 商业规模化使用需购买萤石开放平台的 API 调用量资源包

## 七、数据流说明

无论使用哪种摄像方案，系统内部的处理流程完全一致：

```
摄像设备（Android 手机 / IP 摄像头 / 萤石）
    │
    │  RTMP 推流 / API 拉流
    ▼
读学服务器（SRS 流媒体 + FastAPI）
    │
    │  每 5 秒自动截帧
    ▼
帧图片存储
    │
    │  AI 推理（VLM 分析行为）
    ▼
行为片段记录
    │
    │  会话结束后自动聚合
    ▼
行为报告（guardian 在 App 中查看）
```

## 八、常见问题

**Q：Android 手机锁屏后 App 停了怎么办？**

> 进入"设置 → 电池 → 应用电池管理"，将 IP摄像头 App 设为"无限制"，并开启"自启动"权限。不同品牌手机的菜单位置略有差异。

**Q：手机如何连接到部署在云上的服务器？**

> 读学Eye 通过公网直接推流到服务器，手机只需能正常连接互联网（连 WiFi 即可），无需与服务器在同一局域网。

**Q：画面延迟太高怎么办？**

> 在 App 设置中降低分辨率（640×480）或降低视频质量（50% 以下）。截帧分析对实时性要求不高，5~10 秒延迟完全可接受，不影响报告准确性。

**Q：iOS（iPhone/iPad）能用吗？**

> iPhone 不支持后台持续摄像。iPad（USB-C 接口，iPadOS 17+）理论上支持外接 UVC 摄像头，但挂机体验差且需要额外开发。**强烈建议使用闲置 Android 设备替代**。

**Q：一个 ward 可以绑定多台摄像设备吗？**

> 支持。每台设备独立绑定，分别拥有各自的 `stream_key`。guardian 可以在 App 中查看每台设备的在线状态。

**Q：guardian 可以管理多个 ward 吗？**

> 支持。一个 guardian 账号下可创建并管理任意数量的 ward，每个 ward 可以独立配置分析规则和绑定设备。

**Q：萤石 API 可以接入小米摄像头吗？**

> 不能。萤石是海康威视旗下产品，有独立的开放平台。小米摄像头走米家 IoT 体系，官方没有面向开发者的公开视频流 API，接入难度大，不建议使用。
