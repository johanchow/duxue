# 计划确认卡只保留确认按钮

> 日期：2026-10-24

## 现象与原因

计划确认卡原来同时显示「我再改一句」与「确认这个计划」；有建议时还显示「采用建议」「先不改」。这些按钮与同页持续可用的语音、文字输入重复，让确认动作不够明确。

## 决策

- 确认卡只显示「确认这个计划」按钮；建议文字仍可阅读，不在这张卡上渲染建议操作按钮。
- Ward 直接说出或输入调整、恢复、采纳建议的意图，Planning 更新草稿后再次进入审阅。澄清阶段的建议按钮不属于确认卡，保留原行为。
- 后端现有结构化建议动作暂保留，避免影响其他调用；App 在确认卡上不呈现该动作。

## 验证

- Widget 测试先复现多按钮，再验证确认卡只显示确认按钮。
- `flutter test` 全绿（100 项）；`flutter analyze` 无问题。
