# 图片登记交回空操作时不要说已记录

`plan_intake` 只要求 JSON 对象。模型可以把任务写进 `assistant_text`，同时省略 `operations` 和 `items`；校验会把缺省字段补成空数组，整轮仍算成功。提示词又把「不要编造」写得很硬，图片上的标题和时长不算学生「说出」的内容，看图模型更容易交回空操作。之后只要任务池里已有未排期任务，固定文案就会说「任务已记录在任务池」。

提示词现在把图片里读到的标题和时长视为观察到的内容，并给出一条 `kind=create` 的示例。带图且解析后没有 operations、items、slot_updates 时，直接回复没有识别出新任务，不再进入那条固定文案。有标题但没有时长时仍走原有追问，不入库。`plan_intake` 上报输出摘要，以及是否带图、操作条数和循环状态；原文不进 Grafana。
