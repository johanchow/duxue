# App UI 与 mockup 对齐

- Guardian 顶层采用「孩子 / 决策 / 我的」，将传递放在孩子页的显著主操作中；传递允许多选 Ward，但文字任务提交仍逐个调用既有 `createAssignment` API。
- 多模态传递在当前 App 提供文字、语音、截图三个入口选择。后端尚无语音识别/图片上传契约，故只有文字会实际创建任务，另外两个入口保留为明确的 UI 接入位。
- Guardian 详情以「今日 / 报告 / 设置」组织：进行中不显示专注判定或有效学习分数；今日报告等待 Ward 自评，过往报告和趋势始终可进入。
- Ward 工作台采用「首页 / AI 伙伴 / 成长」：观察控制显示记录状态、关联任务与时长，可暂停或结束；不呈现实时行为结论。当天洞察在自评提交后生成，历史成长入口始终存在。
- 验证：`flutter analyze` 与 `flutter test` 均通过（4 tests）。
