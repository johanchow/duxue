# 除法竖式 SVG 画成右括号而非「厂」

## 线上证据

2026-10-21 09:10（北京时间）trace `1d7418e304724494879ef8af9b3acf85`，用户明确说「六百六十除以一百三十的除法竖式」。`tutoring.turn@v18` 输出了 `130 ) 660`，横线在被除数下方，商位填了 `5`。SVG 结构校验通过，`tutoring.visual-leak-judge@v4` 返回 `leaks=false`，最终 `tutor.visual.kind=svg` 展示。模型未先调用 `widget_guidelines`。

## 根因

SVG 校验只保证语法、安全标签和画布，不检查学科图形惯例；图泄露判官只接收 `describe(visual)` 提取出的可见文字，看不到线段的相对位置。提示词虽要求先调 `widget_guidelines`，此前只有 SVG 结构非法时才会补注规范并重试，结构合法的错误图直接通过。

## 修复

- SVG 首次输出若未加载 `widget_guidelines`，自动注入规范和被拒草稿，重画一次；若重画失败，保留文字并丢弃原图。已有泄露修复请求中也不放行未加载规范的 SVG。
- 重画候选必须保持原 `act`、`content`、`turn`，避免把已确认的 `660 ÷ 130` 改回历史轮次的错误数字。
- `SVG_WIDGET_GUIDELINES` 增加中文除法竖式 `厂` 字形的连接路径、除数/被除数/商位位置示例，明确禁止 `)` 代替竖式括号或横线画在被除数下方。
- 图判官升为 v5，明确未完成的商位不能填数字。没有通过语义关键词或数字扫描在代码里猜图形含义。
