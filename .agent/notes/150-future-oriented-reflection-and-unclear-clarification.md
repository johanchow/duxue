# 面向未来的自我复盘与不明意图澄清

日期：2026-10-22

- 现象：意图 Prompt 只明写总结和回忆自己的经历，未覆盖基于自己经历问“将来怎么做、怎么做更好、怎么避免错误”的 Reflection；`unclear` 固定澄清回复只提“复盘今天”，范围也偏窄。
- 决策：结合本人学习或工作经历、错误、目标谈未来改进，归入 Reflection；没有自我经历语境的一般方法请教仍归 Tutoring。模型提议仍由闭集路由器校验，不添加关键词分流。`unclear` 时的固定回复同步改为任务管理、自我回顾与提问聊天三种选择。
- 当前 `unclear` 路径：普通文本写 Ward 原句和固定澄清回复、记录 Trace、不建 Run、不调用目标 Workflow，原 focus 保留；下一轮重新判断。图片且无 focus 或 focus=Planning 时按既有例外进入 Planning；其他 focus 的图片仍澄清。非法输出或模型网关错误也变成 `unclear`。
- 验证：先写失败测试再修改；增加 3 条离线意图样例。服务端全量测试 604 项通过；Prompt 相关文件 Ruff 通过，仓库级 Ruff 的旧告警不在本次范围。真实模型对个人错误改进、上下文续接改进、一般写作方法分别返回 Reflection、Reflection、Tutoring。
