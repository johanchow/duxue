# Ward 首页内嵌当天计划输入

- Ward 的当天计划整理使用独立的 `/wards/{ward_id}/plans/{date}/intake` 系列接口和 `ward/<ward-id>/plan-intake/` 临时附件路径，不能复用 Guardian 的多 Ward 任务传递接口。
- `VoiceComposer` 是共享层的业务无关组件：左侧大面积长按按钮的默认文案为「按住说话」（可由 prop 覆盖），右侧通过回调交给业务层处理图片。它使用微信式浮层展示实时文字、松开发送与上滑取消，最终语音通过回调返回调用方。
- 调用方可通过 `holdToTalkText` 和可选 `helperText` 将场景标题和说明放进左侧按钮；Ward 首页传入「说今天怎么安排」与「加任务 · 改顺序 · 调时长 · 补遗漏」，不在页面外重复维护这组文案。
- Ward 首页不再显示文本输入框或发送箭头；松开后的最终语音、以及上传完成的图片会直接发送给计划整理模型。
- 模型输出始终是仅在客户端保留的草稿。只有 Ward 点击「确认今天计划」后，服务端才在一个事务中创建新 `Assignment`、写入 `PlanItem` 并确认当天 `DailyPlan`；离开页面会尝试清理临时图片。
- 已开始或完成的计划不允许通过此入口改写，避免覆盖学习会话和完成记录；未开始的当天计划可由 Ward 重新确认。
- 测试约定：覆盖发送草稿、确认后的实际写入、图片临时对象清理和 Ward 越权拒绝等功能结果，不为静态文案或通用 UI 组件单独设测。
