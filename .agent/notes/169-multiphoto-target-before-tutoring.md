# 答疑多图先定目标

日期：2026-10-29

事实源：[`docs/technical/domain-companion.md`](../../docs/technical/domain-companion.md) §1.1。

- 真实 trace `8589b9b475824d92e4f485747c57181e` 中，本轮新图排在三张窗口图后面，主模型仍沿用历史第4题的文字结论。临时编号只能表示本次输入顺序，不能表达问题目标。
- 图片引用只用单次调用里的编号，不再建立持久引用。窗口图片读取继续受 Ward 前缀与 8 张上限控制。
- 本轮有新图时直接用新图，不调用选择模型。只有无新图且窗口有多张旧图时才调用受控多模态组件；无关文本问题可以不选图。返回歧义、不可读或越界编号时先追问。只把选定图交给后续答疑、泄露检查与重试；保留历史原句理解上下文。
- 比较上一张必须由显式 `tutoring_intent=compare_previous_image` 触发；开放文字的比较意图不能靠关键词或正则推断。该标志只加最近一张旧图，不再调用选择模型。
- “全部题目”覆盖范围属于视觉与语义判断，提示词要求逐题说明实际检查范围；单元测试验证输入边界和收窄，不把关键词或正则当作答案正确性判断。
