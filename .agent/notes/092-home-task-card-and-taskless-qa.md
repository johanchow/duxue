# 首页任务卡片与无任务答疑

日期：2026-09-28

- 决策：首页任务卡片是读模型。安排状态来自 Task 的 pool/scheduled/completed；进行中和暂停来自该任务未结束的 StudySession。未排期和今日计划都能点开始，开始不改 Task 的安排状态。
- 决策：学习答疑可以不绑定任务。仅当已有任务会话进行中或暂停、孩子又问了别的时，简短回答并提醒回任务，不结束原会话。
- 实现：首页卡片用 `homeTaskCardKind` 组合 Task.status 与未结束 StudySession。未排期和今日计划确认后才开始；进行中卡片才能暂停或完成。Planning 领域不读取 StudyInterval。
- 实现：好奇心或闲聊落在进行中/暂停的任务会话上时，提示停在 L1，回答末尾提醒回到该任务，不调用完成。
