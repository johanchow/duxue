# 学习执行

事实源：[domain-study](../../docs/technical/domain-study.md)。

## 目标

Study 拥有学习会话、计时和到点开始邀请。任务是否入池、入日程、完成由 Planning 记。进行中和暂停由 StudySession 记。到点未开始时邀请开始，不自动开课。

## 状态

- 已落地：任务四态、会话开始/暂停/继续/完成、跨天放弃遗留会话、首页任务卡、StartCue 卡片。
- 读取邀请时同步打开卡片。没有现场就用 `no_observation` 和兜底句，不调视觉模型和文案模型。
- 未做：到点前的观察租约和真实场景分类。`away` 只有服务传入该标签时才不展示。

## 决策

- Task 只有 `pool` / `scheduled` / `completed` / `cancelled`。`completed` 由 Planning 的明确完成声明或真实 `StudySessionCompleted.v1` 写入。开始学习不改任务安排状态。
- 本地日过后，未完成的 `scheduled` 回到当天任务池，同时把往日未结束的 `active` / `paused` 标为 `abandoned`（`day_rollover`）并解开任务绑定，任务池才可以左滑删除。
- 新开的、不带学习会话的答疑不继承旧线程里未结束的题目。
- StartCue 属于 Study。前一项还在进行也会打开，按钮改为继续或切换。不自动开始、不改期、不通知家长、不写学习事实。卡片 `kind` 为 `start_cue`，登记在 Companion。Planning 只提供 `start_at`。
- 首页在本地时钟的整 5 分钟以及回到前台时刷新邀请。开始提醒只排 `scheduled` 任务；2026-11-04本轮进一步移除由计划末尾自动推导的总结提醒，见下文。
- 无任务答疑可以不绑定任务。已有任务会话进行中或暂停时，问别的只简短回答并提醒回任务，不结束原会话。学习会话结束后答疑不自动关闭，只是不再追加新轮次。
- 暂停和继续须等待服务器确认后更新界面；暂停状态可以直接声明完成。

## 注意

- 本地通知用系统闹钟：当天从没打开 App 排不出去；Android 非精确；别的设备改了状态而本机没再同步时，已排通知仍可能响。
- 2026-11-01 新增[观察求助邀请目标设计](../../docs/technical/domain-study.md#九观察触发的求助邀请目标扩展)：独立于 StartCue，尚未实现；实施前先做 shadow 与误触发复核，不将被动停滞候选当作确定卡壳。
- 2026-11-01 用户复核后补齐[实际干预路径](../../docs/technical/domain-study.md#96-卡壳递梯子和温和回归的实际执行)：停滞递梯子和活动偏离回归共用额度；显式陪伴通道支持卡片/可选轻声提示，无通道不占额度、不声称已干预。当前仍为目标设计。
- 未排期任务左滑走删除接口；已有学习记录返回 409。

- 2026-11-03 用户确认轻量计划原则；配套目标与旧契约差异见 [Study §1.0](../../docs/technical/domain-study.md#10-轻量计划配套调整2026-11-03-已实现待验收)。默认隐藏计时、仅显式钟点邀请、换项与无会话完成声明已实现，待 Gate 2。

- 2026-11-03 后续确认：Sprint 归 Study，为已实现待验收的独立限时挑战；计时与到时不等于会话完成、任务完成或成功专注。契约见 [Sprint 设计](../../docs/technical/domain-study.md#24-sprint主动专注挑战已实现待验收)，首页展示唯一归属计划 PRD。

- 2026-11-03 本轮已实现 Sprint 状态/API/客户端、服务端区间计时与任务完成声明，待 Gate 2；对应迁移32尚未上线，验证记录见[实现 spec](../specs/lightweight-planning-focus-sprint.md)。旧笔记中的目标扩展描述属于此前进度。

- 本轮验收复核：StartCue 和任务显式开始共用执行服务及 Ward 锁；即使旧邀请晚点击，也只换项不并行计时。Sprint 可选会话引用必须属于本人并匹配关联任务，清除时先删挑战再删会话。自动化验证见进行中 spec。

- 2026-11-04 本轮新增Ward `/sprints/preview` 只读口述整理；契约归 [Study §2.4](../../docs/technical/domain-study.md#24-sprint主动专注挑战已实现待验收)。独立`study.sprint-intake`声明式组件/工作流使用结构化候选与Python校验，不建立Task/Session/Sprint或改变答疑Thread。主题可空、时长不默认，确认后才调用既有幂等开始，无新迁移。
- 真实模型冒烟曾发现通用计划提取把“只说主题”理解成登记任务，因此口述整理必须保持独立短提示词，不能混回通用Planning规则；格式异常一律不可用/重试，不能回退20分钟。语义由模型解释，代码只校验结构和授权。

- 2026-11-04 约定提醒投影已改造，待完整验收：`scheduled`按约定钟点，`elapsed`仅按本次执行区间累计，暂停/完成/取消不再排；无日程仍可读取显式执行提醒。提醒方式由Planning确认，完整契约见[领域设计](../../docs/technical/domain-planning.md#约定到时提醒2026-11-04本轮待验收)。本地通知仍依赖App同步，跨设备离线撤回没有新增保证。
