# 答疑答案确认按题型分流

日期：2026-10-20

- 产品口径修正：计算题、问答题在孩子已提出完整答案且能依据原题独立核验时，可以准确确认或纠错；选择题、判断题等可逐项试探的题，不能逐项确认候选项的对错。`submitted` 仍只是孩子提交，不自动等于正确；一次答对也不等于“已掌握”。
- 现象：原提示词一律禁止断言对错，`episode-socrateach-uncertain-correct` 又以字面 `42` 判失败；另一方面 `episode-mathdial-balance` 机械通过时曾有直接确认，说明单纯禁止答案数字和结果类别都不能代表教学质量。
- 改动：版本化主提示词和泄露审核提示词，要求识别孩子本轮是否提出答案、题型是否可逐项试探、能否独立核验；撤掉计算题已提交答案的字面禁令，增加一条未进入首批批次的选择题试探用例。受保护题目不再因主模型自报短“事实”而跳过独立审核（原快路会放过 `选 B。`），`fact_gate` 只保留分类观测；无当前受保护题目的普通问答不增加审核。保留生产同源出口审核及 fail-closed，不用正则替代语义判断。
- 限制：泄露审核本身仍是概率性模型判断，现有离线 `content_not_contains` 仅做字面冒烟；新旧用例均未有人为标成 `confirmed`，不能从机械通过率断言选项试探或错误附和已解决。后续如引入离线语义裁判，须先由教研标注校准集，并报告其误判/漏判；需在真实模型上复跑提示词版本并人工抽核结果。
