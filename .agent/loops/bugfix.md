# Loop: bugfix（先红后绿）

> 目标：先复现、再修复、必沉淀。

## 步骤

1. **复现**：先写一个能**失败**的测试复现 bug（红）。
2. **定位**：找根因，读相关代码与 `.agent/notes/` 是否已记同类坑。
3. **修复**：最小改动让复现测试转绿，且不破坏其他测试。
4. **验证**：全量测试 + lint 全绿。
5. **沉淀（收工）**：把现象 / 根因 / 规避追加到 `.agent/notes/` 里对应领域文件的「注意」（见 `00-index.md`）。不新建编号笔记。
6. **commit 前 review**：`git diff` 无调试残留、无遗漏；笔记与修复同一 commit。

## 硬约束

- 无复现测试不许改代码（先红后绿）。
- 不记坑 = 未收工。
