## 实现顺序与验收

- [x] 修复已确认的跨域外键缺陷。Ward 绘本保留来源 UUID 与索引。已在 PostgreSQL 测试业务库应用迁移 46，课件持久化与 Ward 绘本相关 11 项测试通过。
- [x] **统一写侧**。扩展课件版本库为 EduArtifact，迁入已有保存的课件、绘本与版本指针。两端旧入口和新工具调用同一套写命令。用 PostgreSQL 验证并发 CAS、命令重试、撤销后改写、临时作品四小时到期、已保存作品独立重开及修订产生一次足迹。资产迁移核对数量和当前版本，保留可回滚路径。
- [x] **打通规划器与门禁**。双端从真实发送入口调用模型选择角色获准的 Skill，通用问答有兜底。Ward 本轮意图判断只做一次，Sprint 仅影响偏题提醒。GateRunner 在命令产生副作用前和最终响应前执行所需领域检查。分别测试越权、门禁拒绝、门禁超时和模型伪造核验结论，检查数据库无越权写入、客户端无提前泄露。
- [x] **成人整页与多页批改**。工作台接收有序图片，保留页码、题号、作答与题面对应关系，逐题解题核验后生成 grading_report。遮挡、低置信及无法证实等价的题显示“待人工复核”。测混合清晰度、多页题号重复、保存、筛选和重开。
- [x] **成人备课与自验出题**。由主题和要求生成 lesson_pack；每道变式独立调用 ProblemSolving 自解自验，结果绑定题目版本，修改题目后重验。未通过自验的题展示状态。测部分失败、修订、撤销、保存和重开。以上成人场景均可在未关联学生时完成。
- [x] **退场**。先将仍使用 Planning 的 Sprint 行为转入 Study，将晚间客观报告从 Reflection 命名和运行依赖中分离，再删除旧路由、工作流、App 入口、Admin 配置及相关遥测。历史消息免迁移；保留当前有效的晚报、解题凭证与创作足迹。验收覆盖主动挑战、结束挑战、报告版本重开、旧接口退场和离线评测加载。
- [x] **联合验收**。跑服务端、Flutter 和涉及的 Admin 测试，核对 PostgreSQL 业务库迁移、Admin 草稿回读与实例加载。复用适用的 Langfuse 评测，补足两种新产物与门禁失败用例。Android 真机验证从成人发送多页图片到查看和保存结果，以及 Ward 本轮由探索转为索要答案的场景。
