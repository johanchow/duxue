# 答疑联网搜索
按已确认的方案，由答疑 Agent 在有学习目的且需要外部证据时调用搜索工具，复用现有图审。

## 实施与验收
- [x] 注册可选工具并升级本地 Admin 草稿；旧快照兼容。
- [x] 接入 IQS 网页与图片检索、动态候选数、共享检索截止时间和最多一次补搜。
- [x] 回合内候选引用及图注经实际缩略图审核；受权消息附件支持显示、回看和来源。
- [x] APEC 追问的真实模型路由选择图片，时政资料选择网页，一般知识和娱乐请求未搜索。真实图审拒绝白图冒充会场，接受用白色色卡讲颜色。
- [x] 模拟供应商下验证附件读写、越权拒绝、搜索超时和图审拒绝；记录搜索 span 和 App 首帧耗时。
- [x] 本地 IQS 凭证已联通网页和图片接口。APEC 追问在本地草稿真实回放中搜索一次、取得五个候选，实际下载一张并通过图审，服务端用时 12.3 秒。
- [x] 已将搜索工具、导师绑定与两项审核增量写入测试 Admin 工作草稿，删除独立搜索 JSON 后经本机 API 回读并真实调试返回 web_photo。
- [x] 通过真实 Workflow dispatcher 回归照片附件持久化和本人读取；最近一条 APEC 消息已重新关联原审核图片。
- [ ] 测试环境启用搜索配置后，在客户端核对照片、出处及首帧耗时。
- [ ] 用户验收。

实现与启用见[答疑表达设计](../../docs/technical/domain-tutoring-presentation.md#联网资料与真实照片)。
