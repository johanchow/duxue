# 2025 北京高考九科本地卷面评测

Gate 1 已由用户确认，含九科真实模型执行。

目标是衡量读学 Guardian 导师解析在逐题输入、首次作答条件下可交付的卷面分。每科独立报告，英语采用笔试卷。

## 验收标准

- [x] 九科各一卷，原 PDF、来源、角色、摘要可追溯。按内容纠正地理附件角色。对照原卷和参考解析检查题号连续性、跨页图表、选答规则、小问分值与卷面满分。
- [ ] 每道题的输入只含作答说明、原题及必要材料；实际发出的文本和图片均可审计。同一材料的关联小问一起提交，按小问分别计分。
- [x] 使用本地服务的 guardian_explain 正常入口、隔离的测试身份和固定配置；归档首次可见答卷、附件、状态、时长和题库命中信息（不可观测时标未知）。支持按科运行与断点续跑，避免重复提交或择优。
- [x] 判卷端独立读取参考答案。固定客观题等价规则、主观题采分点和作文档次，允许等价论证。区分来源提供与自行制定的细则。开放题独立语义裁判逐项给证据，低置信、缺细则和争议项可人工复核。完整自动评分标明估分，复核后记录新版本。
- [x] 每科产出得分/原卷满分和逐题扣分明细。已交付空答计零，系统未运行、缺题图、判分失败均单列；存在未决项时报告已定分和可能区间。全部覆盖且判分完毕才出该卷完整成绩。

## 实现计划与测试

- 在 duxue-server/evals 下增加整卷数据协议及本地命令，复用 evals/local 的配置快照与结果归档机制。数据准备、校验、作答、评分、报告分步运行。模型通过配置的推理服务调用，结果本地存储。
- 在 duxue-server/tests 下覆盖地理文件反标、答案隔离、题图缺失、跨页材料、选答计分、部分分与作文区间、重试恢复及分母一致性。运行相关回归和仓库要求的测试。
- 每科先作答一题验证真实端到端输入输出，冻结试卷与评分版本后运行九卷；若用冒烟输出修改了产品配置，在报告记录。命令和结果解释归入 docs/technical/eval-offline.md。

## 本轮实测与验收边界

两次汇总均覆盖 208 个计分题号且待判分为零。端到端首答 247/1000，一次失败补答后 371/1000。按卷结果、评分依据、原题与参考页的本地入口见 `duxue-server/var/exams/beijing-2025/REPORT.md`。参考题面与标准答案文件已用 SHA 固定；英语采用笔试卷。未作答成功的情况均保留，不能把完成评测解读为交付了全套解答。

题面隔离与计划存在一项差异：首答按原 PDF 页区间点题，有些输入带本卷相邻试题，但无答案页；语文和英语共用材料按题组输入，补答可定位的独立题尽量裁边。严格逐题去除所有邻题未在本批实现。此次成绩只代表上述输入方式和批量负载。

本次使用独立测试实例及已有草稿快照；首答并发最高 8，补答并发最高 5，部分时段重叠。评测结果与评分证据存本地；产品服务沿用测试环境既有链路遥测配置。复跑命令显式关闭可选遥测。
