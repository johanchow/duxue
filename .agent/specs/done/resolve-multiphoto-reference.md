# resolve-multiphoto-reference spec

## 做什么 / 为什么
多张历史图与本轮新图同时进入答疑时，优先使用可读新图；只在没有新图且有多张旧图时解析指代，避免沿用旧图结论概括新图。

## 验收标准
- [x] 本轮有可读新图时直接选全部新图，不调用选择模型；仅显式比较标志可加最近一张旧图。
- [x] 没有新图时，一张旧图直接使用，多张旧图才由模型按本次调用的编号选择；无关文字问题不附图。
- [x] 图片引用只用本次调用的编号，不向模型暴露存储路径。
- [x] 答疑与泄露检查只接收目标图及必要关联图，图片读取失败不猜测。
- [x] 要求检查全部题目时逐题标识已检查范围，不能概括未检查题目。
- [x] 多图指代回归测试与服务端测试全绿，记录目标图观测字段。
- [x] 用真实 trace 的当前图片核对轮次建离线用例，保留本机原图并记录重放结果。

## 实现计划（Gate 1：填完等人确认，不许自转）
- 影响文件：图片目标模块、答疑工作流与提示词、请求协议、相关测试、`domain-companion.md` 与笔记。
- 测试计划：先构造连续多图和新图覆盖旧图的失败用例，再实现目标选择；补比较、歧义、读取失败、全部检查及授权边界测试；运行服务端相关测试。
