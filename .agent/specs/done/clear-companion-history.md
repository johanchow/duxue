# 清空可见历史并重新开始对话

## 做什么 / 为什么
学生可在对话框右上角清空历史列表，原消息、附件、运行与审计数据保留，下一句开启新 Thread。任务、计划、学习计时及长期记忆不受影响。

## 验收标准
- [x] 清空需二次确认，明确告知历史数据仍保存；取消无副作用，失败保留对话并支持重试。
- [x] 服务端按 Ward 维护历史代次；旧代次不参与 current、指定 Thread、跨 Thread 分页、图片和事件读取，不能继续输入或重放旧命令。
- [x] 清空事务递增代次、解除旧 focus、终止可恢复 Run；迟到回复不能写回或作为成功回复返回。新 Thread 上下文为空。
- [x] 消息、图片、Checkpoint、Trace 保留；任务、计划、计时和记忆不改变；清空请求可幂等重试。
- [x] App 清理消息、图片、草稿卡、游标与本地 Thread；在途历史/图片/发送请求不能复活旧状态。
- [x] 服务端、Flutter 行为测试、静态检查与迁移校验通过。
