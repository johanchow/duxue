# ward-inline-plan-intake spec

## 做什么 / 为什么
将 Ward 首页底部「跟我说今天怎么安排」从打开弹层的入口改为常驻的多模态计划输入栏：左侧是大面积的长按语音按钮，右侧是上传图片按钮。语音转写采用微信式的录音反馈；语音或图片由服务端整理为当天任务/计划草稿；只有 Ward 明确确认后，草稿才会写入当天任务池和计划。

## 验收标准
- [x] 提供独立、可复用的「长按说话 + 图片」组件：左侧占主要宽度的长按按钮默认显示可配置的「按住说话」；右侧为可配置回调的上传图片按钮。组件不耦合任务、计划或图片上传 API。
- [x] 长按语音时显示微信式的浮层反馈：开始录音、松开发送、上滑取消三个状态清晰可辨；浮层显示实时转写文本，松开后触发调用方的最终转写回调，上滑取消则不提交。录音失败或最长 60 秒结束时显示可恢复反馈。
- [x] Ward 首页使用该组件：语音最终转写会直接提交当天草稿整理；上传图片按钮选择 JPG/JPEG/PNG/WebP 后上传并直接提交整理，不再展示旧文本输入框、发送箭头或点击式录音。
- [x] 发送文字、转写或图片后，服务端只为当前 Ward 的当天任务池和计划生成结构化草稿：可新增任务、引用已有任务、调整顺序或时长；不得修改其他 Ward、跨天计划或直接持久化结果。
- [x] 首页原地展示 AI 回复与当天计划草稿；Ward 可继续补充或修改，且只有点击明确的「确认今天计划」才原子地创建新任务并保存、确认当天计划。关闭/离开页面或取消时不创建任务或改动计划，并清理临时图片。
- [x] 失败、权限拒绝、录音/上传失败和 AI 解析失败均保留已有可编辑文字或草稿，并给出可恢复反馈；现有任务的确认式开始/暂停/完成行为不变。
- [x] 覆盖功能性交互而非静态文案或通用 UI：点击麦克风后的录音状态及提交、选择图片后的上传与提交、草稿确认后实际创建/更新当天任务和计划，以及取消不写入；`flutter analyze`、`flutter test` 与服务端相关 `pytest` 全绿。

## 实现计划（Gate 1：填完等人确认，不许自转）
- 影响文件：
  - `duxue-app/lib/features/day_story_pages.dart`：用新组件替换当前首页的文本/发送式 `VoiceComposer`；语音最终文本与图片上传完成后直接发起当天草稿整理，保留草稿确认区和刷新逻辑。
  - `duxue-app/lib/shared/voice_composer.dart`：直接重构既有可复用组件，封装实时 ASR、长按/上滑取消、微信式录音浮层、可配置按钮文案和图片回调；不知晓任何业务 API。
  - `duxue-app/lib/core/api_client.dart`：新增 Ward 当天计划临时图片上传、草稿整理、确认与清理 API 封装。
  - `duxue-server/app/{main.py,schemas.py}` 与新增或扩展计划整理服务：用 `current_ward` 鉴权，以 Ward ID 和当天日期限定临时附件、候选任务及计划草稿；服务端读取图片并调用模型，校验结构化结果。
  - `duxue-server/app/storage.py`（按需）：增加 `ward/<ward-id>/plan-intake/` 临时对象的受控上传、存在性验证和清理；不复用 Guardian 的附件前缀或权限。
  - `duxue-server/tests/`、`duxue-app/test/`、`.agent/notes/`：覆盖上述实际操作结果和权限/清理边界，并记录以「按天」为唯一计划作用域的决定。
- 服务端契约：草稿请求携带 `content`、当前对话/草稿、最多 4 个临时附件 key；响应包含 AI 文本、候选新任务和当天计划项。确认接口由 Ward 自身调用，在单一事务中创建候选 `Assignment`、写入该 Ward 当天 `DailyPlan/PlanItem` 并确认计划；服务端重新校验 Ward 所有权、日期和附件前缀。
- 测试计划：Flutter 以 fake API 验证长按后松开会将最终转写提交为草稿、上滑取消不会提交、点击图片上传后会提交草稿、确认后调用实际确认 API；不对静态文字或通用视觉细节做测试。保留后端的 fake LLM 边界测试并运行 `flutter analyze`、`flutter test`、`.venv/bin/pytest tests -v`。

## 备注
- 现有 `/task-intake/*` 为 Guardian 专用接口，且按 Guardian 关联的多个 Ward 分配任务，不能直接复用于 Ward；本功能需有 Ward 专用、按日作用域的接口与临时附件路径。
- AI 的结果仍是可审阅草稿，绝不绕过 Ward 确认自动写入任务或计划。
- 本次交互修订以「按住说话」为准：松开即提交最终语音，上滑取消。图片选择、上传和计划整理属于 Ward 首页业务层；组件仅暴露图片点击回调，确保可用于其他业务场景。
