# 官网首页产品操作演示视频

## 做什么 / 为什么
制作约70–75秒、带中文字幕的产品操作演示，依次展示语音输入、苏格拉底式引导、多形式讲解、冲刺挑战；验收后嵌入现有OSS官网首页。

## 验收标准
- [x] 输出16:9、1920×1080、H.264 MP4及封面，中文字幕直接嵌入画面，并保留独立字幕文件；必要的发音演示保留声音。
- [x] 四个卖点都有可见操作和结果，不仅是标题文字或宣传幻灯片；只展示当前已实现能力，不展示未实现的报告、实时监控或AI生成讲解视频功能。
- [x] 纯语音：录音入口 → 说出问题 → 转写/发送 → AI回复；字幕明确提问和说思路无需打字/手写，不暗示替孩子写作业。
- [x] 苏格拉底式：一个简短问题，展示至少两轮“追问/提示 → 孩子尝试”，不以直接给最终答案作为演示卖点。
- [x] 多形式讲解：清晰展示compare对比卡、pronunciation发音播放、visual图形讲解三个画面；示例内容适合清晰短片展示。
- [x] 冲刺挑战：口述目标 → 确认挑战 → 倒计时 → 暂停/继续；不把挑战结束误说为作业自动完成。
- [x] 以测试账号/演示题目录制；若使用真实组件加演示数据，片中及网页明确标注为功能演示，不冒充真实在线AI响应或真机录屏。
- [x] 浏览器/手机检查字幕可读、操作焦点清晰、音画同步；ffprobe核对编码、尺寸、时长，抽帧人工检查每章字幕与场景。
- [ ] 用户视频验收后再上传到下载Bucket并接入官网；视频采用版本化对象名，页面提供播放控件、封面与移动端内联播放，不影响既有APK自动发布。

## 实现计划（Gate 1：填完等人确认，不许自转）
- Gate 1已确认：用户连接安卓手机并明确授权录制和制作成片。ADB已识别小米2211133C设备，采用实际App操作录屏。
- 先确认真实录屏或“真实Flutter组件＋演示数据”方式；真机方式需要用户连接安卓设备、启用USB调试并准备测试身份。用户也可提供现成录屏，但不要求其自行剪辑。
- 默认70–75秒：0–5秒开场；5–18秒语音；18–33秒苏格拉底式引导；33–53秒依次展示对比/读音/图形；53–67秒冲刺挑战；最后5秒展示下载入口。
- 复用现有App界面与组件，不重新发明一套网页仿App；录制/合成脚本与字幕源放独立演示目录，MP4等大文件放ignored output后上传OSS，不提交二进制到Git。
- 本机已有ffmpeg/ffprobe；当前ffmpeg未显示drawtext/ass字幕滤镜，可用字幕透明图层合成或安装支持字幕的工具链，实际选型实现前核实，不绕过仓库环境约定。
- 官网接入只改`download-page/index.html`及必要发布支持；视频素材须有独立可重复发布步骤，不能让每次APK构建都重新上传视频。
- 文档事实源采用部署文档的官网素材部分；关键决策归`.agent/notes/app.md`。视频交付/官网接入各自记录实际校验结果；Gate 2待用户验收。
