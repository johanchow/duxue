# Guardian 图上距离标注核验

## 做什么 / 为什么
复用 Guardian 读题、裁图和解题核验，把纸带等图中的距离端点传到讲解，并对照独立的 T1 低思考配置。

## 验收标准
- [x] 原图未确认的标注触发有界复读。只有成功且授权的裁图可以作为端点证据，回执可回查选区。
- [x] 用同一组端点核验主备路线的距离关系，并保证交付中的关键公式复用同一绑定。
- [ ] 用物理 16 及同类试题核对结果，单独比较低思考强度的耗时和正确性。

## 实现计划（Gate 1：填完等人确认，不许自转）
- 用户已确认此前的端点绑定、定向核验和独立耗时对照方案。
- 在 Guardian 的 Admin 候选快照启用结构化距离证据。利用已有读题、复读、主备和讲解重试，提供确定性距离核验。
- 定位模型返回小问、图、选区和印刷符号，服务端裁图并绑定回执。错图重新定位，格式错复用切片，校验逐图小问覆盖。未确认小问与可交付部分分别处理。
- 测试授权裁图、证据缺失和冲突、主备核验、讲解输出及旧配置兼容，随后跑冻结题图的真实对照。
