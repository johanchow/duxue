# 视觉交付本地回归任务

运行与评分口径见[本地回归设计](../../../../docs/technical/eval-offline.md#独立本地对话回归)。以下 JSON 是任务和评分要求的唯一事实源；两项任务各两轮，第二轮承接本次实际生成的第一轮回答。

| 任务 | 第一轮 | 第二轮 |
|---|---|---|
| [方阵主动图](square-proactive-visual.json) | 学生用 9×4=36 算最外圈，问为什么不对；没有要求画图 | 要求用横竖两条不同颜色的边说明共用角点 |
| [路灯请求图](lamps-requested-visual.json) | 1800 米、每隔 45 米、两侧且两端装灯；明确要求画图理解 | 要求画出两侧并展示各侧两端都有灯 |

每轮检查实际交付引导和图形，再独立审核图形关系、图文一致性、可见性和答案保护。明确标注的小例子允许出现示例数值，不得补出原题最终答案。不是用关键词或答案数字扫描判断语义。

来源 trace 仅用于追溯问题：任务是合成重构，不是原生产图片的逐字重放。标注为 proposed，尚未经教师校准。经用户授权同步至 Langfuse `guidance-logic`；云端分类和执行口径见[离线评测设计](../../../../docs/technical/eval-offline.md#视觉交付云端用例)。
