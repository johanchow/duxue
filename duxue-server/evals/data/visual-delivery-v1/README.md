# 视觉交付本地回归任务

运行与评分口径见[本地回归设计](../../../../docs/technical/eval-offline.md#独立本地对话回归)。各任务的 JSON 文件定义本地回归输入与评分要求。两轮任务的第二轮承接本次实际生成的第一轮回答。

| 任务 | 第一轮 | 第二轮 |
|---|---|---|
| [路灯请求图](lamps-requested-visual.json) | 1800 米、每隔 45 米、两侧且两端装灯；明确要求画图理解 | 要求画出两侧并展示各侧两端都有灯 |
| [正方体展开图](cube-net-proactive-visual.json) | 学生难以从文字想象纸片的位置。检查主动配图、布局正确和保留相对面的推理 | 单轮任务 |

每轮检查实际交付引导和图形，再独立审核图形关系、图文一致性、可见性和答案保护。明确标注的小例子允许出现示例数值，不得补出原题最终答案。不是用关键词或答案数字扫描判断语义。

任务使用合成输入。路灯的来源 Trace 用于追溯原问题，正方体展开图为原创用例。标注为 proposed，尚未经教师校准。云端分类和执行口径见[离线评测设计](../../../../docs/technical/eval-offline.md#视觉交付云端用例)。
